Installation von PyTorch mit CUDA & PyG in Conda

Schritt-für-Schritt-Anleitung zur sauberen Installation von PyTorch mit GPU-Beschleunigung (CUDA) und PyTorch Geometric in einer isolierten Conda-Umgebung.

📅 30. Jun 2026 ⏱️ ~2 Min. Lesezeit (322 Wörter) #Conda #CUDA #PyTorch #Python #Deep Learning
📑 Inhaltsverzeichnis ▾
  • 1. Frische Conda-Umgebung erstellen
  • 2. PyTorch mit passenden CUDA-Binaries installieren
  • 3. Version und CUDA-Laufzeit überprüfen
  • 4. PyTorch Geometric (PyG) und C++-Erweiterungen installieren
  • 5. Vollständiger Hardware-Verifikationstest

Die Einrichtung von PyTorch mit Hardwarebeschleunigung (CUDA) und kompilierten C++/CUDA-Erweiterungsbibliotheken (wie PyTorch Geometric / PyG) führt bei unpassenden Versionen häufig zu Binärkonflikten. Der folgende Ablauf stellt die konsistente Kompatibilität zwischen PyTorch, der CUDA-Laufzeit und den PyG-Wheels sicher.

1. Frische Conda-Umgebung erstellen

Beginnen Sie stets mit einer neuen Umgebung und einer stabilen Python-Version (Python 3.10 oder 3.11 bieten aktuell die breiteste Unterstützung für Deep-Learning-Bibliotheken):

conda create --name torch_cu python=3.11 -y
conda activate torch_cu

2. PyTorch mit passenden CUDA-Binaries installieren

Aktualisieren Sie zunächst pip innerhalb der neuen Umgebung und installieren Sie PyTorch über den offiziellen CUDA-Index:

conda install pip -y
python -m pip install --upgrade pip

# PyTorch, torchvision und torchaudio mit CUDA-Unterstützung installieren
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

Hinweis: Falls Ihre GPU eine neuere CUDA-Version erfordert (z. B. CUDA 12.4 oder 13.0+), passen Sie die Index-URL entsprechend an (cu124 bzw. cu130).

3. Version und CUDA-Laufzeit überprüfen

Prüfen Sie vor der Installation weiterer Bibliotheken die exakte PyTorch-Version und das erkannte CUDA-Backend:

python -c "import torch; print('Torch:', torch.__version__); print('CUDA Runtime:', torch.version.cuda); print('CUDA Available:', torch.cuda.is_available())"

Erwartete Ausgabe:

Torch: 2.x.x+cu121
CUDA Runtime: 12.1
CUDA Available: True

4. PyTorch Geometric (PyG) und C++-Erweiterungen installieren

Installieren Sie torch-geometric zusammen mit den hardwarebeschleunigten C++-Kernels (pyg_lib, torch_scatter, torch_sparse, torch_spline_conv). Passen Sie den Wheel-Link exakt an Ihre installierte PyTorch- und CUDA-Kombination an:

pip install torch-geometric

# Beispiel für PyTorch 2.3.0 mit CUDA 12.1 (an eigene Version anpassen)
pip install pyg_lib torch_scatter torch_sparse torch_spline_conv -f https://data.pyg.org/whl/torch-2.3.0+cu121.html

5. Vollständiger Hardware-Verifikationstest

Führen Sie folgenden Einzeiler aus, um sicherzustellen, dass die Grafikkarte ordnungsgemäß erkannt wird und alle PyG-Erweiterungen fehlerfrei geladen werden können:

python -c '
import torch
import torch_geometric
import pyg_lib, torch_scatter, torch_sparse

print(f"PyTorch Version:    {torch.__version__}")
print(f"CUDA Available:     {torch.cuda.is_available()}")
if torch.cuda.is_available():
    print(f"Device Count:       {torch.cuda.device_count()}")
    print(f"Primary GPU:        {torch.cuda.get_device_name(0)}")
    print(f"VRAM Allocated:     {torch.cuda.memory_allocated(0) / 1024**2:.1f} MB")
print("PyG & C++ Kernels:  Erfolgreich geladen!")
'

Wird Ihr Grafikprozessor (z. B. NVIDIA GeForce RTX ...) angezeigt und meldet der Test Erfolg, ist die Umgebung einsatzbereit für anspruchsvolles Deep-Learning-Training.
