Vektorgrafiken (SVG) direkt in LaTeX einbinden

Anleitung zur Nutzung des svg-Pakets und \includesvg in LaTeX – inklusive Inkscape-Konfiguration und –shell-escape.

📅 17. Jul 2024 ⏱️ ~1 Min. Lesezeit (197 Wörter) #Howto #LaTeX #Vektorgrafik #Inkscape

Das bekannte LaTeX-Paket graphicx bindet Rastergrafiken (PNG, JPG) und PDF-Vektorgrafiken über folgenden Befehl ein:

\includegraphics[optionen]{dateiname}

Standardmäßig unterstützt graphicx jedoch kein SVG. Mit dem mächtigen Paket svg lässt sich diese Lücke elegant schließen.

1. Inkscape installieren

Das svg-Paket nutzt im Hintergrund Inkscape, um Vektorgrafiken verlustfrei in PDF-Layer mit passenden LaTeX-Schriftarten umzuwandeln.

  • Windows:
    winget install -e --id Inkscape.Inkscape
  • Linux (Ubuntu/Debian):
    sudo apt install inkscape

2. Minimalbeispiel (.tex)

Kopiere deine grafik.svg direkt in deinen Dokumentenordner (neben die .tex-Hauptdatei):

\documentclass{article}
\usepackage{svg}

\begin{document}
    \begin{figure}[htbp]
        \centering
        \includesvg[width=0.8\textwidth]{grafik}
        \caption{Verlustfreie Vektorgrafik aus einer SVG-Datei.}
    \end{figure}
\end{document}
  • Die Dateiendung .svg kann optional weggelassen werden.
  • Skalierungsparameter (width, height, scale) funktionieren analog zu \includegraphics.

Typische Fehler und Lösungen

Fehler: image_svg-tex.pdf' is missing

Package svg Error: File `grafik_svg-tex.pdf' is missing. \includesvg{grafik}
💡
Lösung: --shell-escape aktivieren
LaTeX benötigt die Erlaubnis, das externe Programm Inkscape aufzurufen. Füge dazu das Compiler-Flag --shell-escape zu deinem Build-Befehl hinzu.

In TeXstudio unter Optionen $\rightarrow$ TeXstudio konfigurieren $\rightarrow$ Befehle $\rightarrow$ PdfLaTeX:

pdflatex.exe -synctex=1 -interaction=nonstopmode --shell-escape %.tex

Fehler: Inkscape version not detected

⚠️
Lösung: Inkscape im System-PATH hinterlegen
Dieser Fehler tritt auf, wenn LaTeX die Binärdatei inkscape nicht im Suchpfad findet. Stelle sicher, dass der Inkscape-Pfad (unter Windows meist C:\Program Files\Inkscape\bin) in den Umgebungsvariablen (PATH) eingetragen ist.
