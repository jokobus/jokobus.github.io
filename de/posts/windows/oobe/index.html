Windows OOBE umgehen

Anleitung zum Umgehen des Windows ‘Out of Box Experience’ Einrichtungsassistenten (Lokales Konto, Audit Mode).

Was ist OOBE?

OOBE steht für die Windows Out-of-Box Experience – der Einrichtungsassistent, der nach einer Neuinstallation von Windows 11 oder Windows 10 erscheint. Hier werden Sprache, Tastaturlayout, Netzwerkverbindung und Benutzerkonten konfiguriert.

Problem 1 & 2: Microsoft-Konto-Zwang & Offline-Installation

Seit Windows 11 (insbesondere Versionen ab 22H2) erzwingt Microsoft eine aktive Internetverbindung und den Login mit einem Microsoft-Konto während des Setups. Wer keine Netzwerkverbindung zur Hand hat oder aus Datenschutzgründen ein lokales Benutzerkonto bevorzugt, kommt am Bildschirm „Verbindung mit einem Netzwerk herstellen“ zunächst nicht weiter.

📝
Note
Ein Microsoft-Konto kann jederzeit nachträglich in den Windows-Einstellungen verknüpft werden, falls Clouddienste (wie OneDrive oder Microsoft Store) gewünscht sind. Die Ersteinrichtung mit lokalem Konto verhindert unerwünschte automatische Benennungen des Benutzerverzeichnisses (C:\Users\...) und schränkt initiale Telemetrie ein.

Lösung 1: Netzwerkzwang umgehen (BYPASSNRO)

Der sauberste, offiziell in Windows integrierte Weg ist der Befehl bypassnro (Bypass Network Requirement Option).

  1. Sobald der Bildschirm „Verbindung mit einem Netzwerk herstellen“ erscheint, folgende Tastenkombination drücken:
    • Umschalt + F10 (bzw. Shift + F10, bei manchen Laptops Fn + Umschalt + F10).
  2. Es öffnet sich die Windows-Eingabeaufforderung (CMD). Dort folgenden Befehl eingeben und mit Enter bestätigen:
    OOBE\BYPASSNRO
  3. Der PC startet automatisch neu.
  4. Nach dem Neustart erscheint beim Netzwerk-Bildschirm eine neue Option:
    • Auf „Ich habe kein Internet“ klicken.
    • Im folgenden Schritt auf „Mit eingeschränkter Einrichtung fortfahren“ klicken.
  5. Nun kann wie gewohnt ein lokaler Benutzername und ein Passwort festgelegt werden.
💡
Tip
Klassischer E-Mail-Trick: Falls eine Internetverbindung besteht, kann im Anmeldefenster auch eine gesperrte Dummy-Adresse wie no@thankyou.com mit beliebigem Passwort eingegeben werden. Windows meldet einen Fehler („Es ist ein Fehler aufgetreten“) und bietet sofort die Erstellung eines lokalen Kontos an.

Problem 3: PC vorbereiten vor Verkauf oder Weitergabe (Audit-Modus)

Wenn du einen PC zusammenbaust, konfigurierst oder verkaufst, möchtest du meist:

  • Treiber, BIOS/Firmware und Software-Updates vorab installieren.
  • Hardware-Funktionen und Stabilität prüfen.
  • Sicherstellen, dass der Empfänger beim ersten Start trotzdem die saubere, originale OOBE-Willkommensseite sieht – ohne verbleibende persönliche Daten oder WLAN-Passwörter.

Lösung 2: Windows Audit-Modus nutzen

Methode 1 — Sysprep Audit-Modus Shortcut (Empfohlen)

Microsoft bietet für Systemintegratoren und OEMs den sogenannten Audit-Modus (Überwachungsmodus) an.

  1. Direkt auf dem ersten OOBE-Bildschirm (Länderauswahl) drücken:
    • Strg + Umschalt + F3 (bzw. Ctrl + Shift + F3).
  2. Der Rechner startet sofort neu und meldet sich automatisch als lokaler Administrator im Audit-Modus an.
  3. Auf dem Desktop öffnet sich das Dialogfenster des System Preparation Tool (Sysprep).
  4. Nun können alle nötigen Treiber, Programme und Tests durchgeführt werden.
⚠️
Warning
Das offene Sysprep-Fenster nicht schließen! Falls es versehentlich geschlossen wurde, kann es über die Ausführen-Zeile oder CMD neu gestartet werden: C:\Windows\System32\Sysprep\sysprep.exe
  1. Nach Abschluss der Einrichtung:
    • Im Sysprep-Fenster unter Systembereinigungsaktion die Option Out-of-Box-Experience (OOBE) für System aktivieren wählen.
    • Den Haken bei Verallgemeinern setzen (Generalize).
    • Bei Optionen für Herunterfahren auf Herunterfahren stellen.
    • Mit OK bestätigen.
  2. Sobald der neue Besitzer den Computer einschaltet, landet er direkt im frischen OOBE-Setup.

Methode 2 — Temporärer Registry-Eintrag

Falls das Setup manuell per Registrierungsdatenbank übersprungen werden soll:

▸ Registry-Anleitung anzeigen
  1. Im Setup Umschalt + F10 drücken, um die Eingabeaufforderung zu öffnen.
  2. Das Setup temporär als abgeschlossen markieren:
    reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /t REG_DWORD /d 1 /f
shutdown /r /t 0
  3. Nach dem Neustart springt Windows direkt zum Login.
  4. Nach getaner Arbeit den Eintrag wieder entfernen:
    reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /f
shutdown /r /t 0
