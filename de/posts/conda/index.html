Warum Conda?

Conda ist ein quelloffenes Paket- und Umgebungsverwaltungssystem, das speziell für Data Science, maschinelles Lernen und wissenschaftliches Rechnen entwickelt wurde. Im Gegensatz zu reinen Python-Paketmanagern wie pip bietet Conda wesentliche Vorteile:

  • Isolierte Umgebungen: Jedes Projekt verfügt über seine eigene abgeschlossene Umgebung. Dadurch werden Versionskonflikte zwischen Bibliotheken (z. B. PyTorch 2.x vs. TensorFlow 2.x) zuverlässig vermieden.
  • Binäre Nicht-Python-Abhängigkeiten: Conda kann vorkompilierte Systembibliotheken (wie CUDA Runtimes, cuDNN, OpenBLAS oder Graphviz) direkt in der Umgebung installieren – ganz ohne Root-/Administratorrechte.
  • Plattformübergreifende Konsistenz: Garantiert identische Auflösung von Abhängigkeiten unter Linux, macOS und Windows.

Installation: Miniforge vs. Anaconda

Während das klassische Anaconda ein schwergewichtiges Bundle mit zahlreichen vorinstallierten GUI-Tools darstellt, ist heute Miniforge der moderne Standard. Miniforge ist minimal, quelloffen und nutzt standardmäßig den community-gepflegten Kanal conda-forge.

Linux / macOS

# Installationsskript herunterladen
wget https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh

# Skript ausführen
bash Miniforge3-Linux-x86_64.sh

Anschließend das Terminal neustarten oder die Konfiguration neu laden (source ~/.bashrc bzw. source ~/.zshrc).

Windows

Laden Sie das Installationsprogramm Miniforge3-Windows-x86_64.exe von der Conda-Forge Website herunter und folgen Sie dem Assistenten.

Installation überprüfen

conda --version
conda info

Konfiguration (.condarc)

Conda kann global (~/.condarc) oder pro Projekt angepasst werden. Beispielsweise können benutzerdefinierte Speicherpfade für Umgebungen und heruntergeladene Pakete hinterlegt werden:

# ~/.condarc
envs_dirs:
  - ~/miniconda3/envs
  - /data/shared/conda/envs

pkgs_dirs:
  - ~/miniconda3/pkgs
  - /data/shared/conda/pkgs

channels:
  - conda-forge

Die aktive Laufzeitkonfiguration lässt sich jederzeit anzeigen:

conda config --show

Umgebungen (Environments) verwalten

1. Neue Umgebung anlegen

Geben Sie beim Erstellen stets den Namen und die gewünschte Python-Version an:

# Umgebung mit spezifischer Python-Version erstellen
conda create --name ml_projekt python=3.11

# Umgebung direkt mit Paketen initialisieren
conda create --name cv_projekt python=3.10 numpy opencv matplotlib

Syntax für Versionsbeschränkungen

TypSyntaxBeispiel / Bedeutung
Fuzzy Matchpython=3.11Jedes 3.11.x Release
Exaktpython==3.11.8Exakt Version 3.11.8
Vergleichpython>=3.103.10 oder neuer
Bereich (UND)"python>=3.10,<3.12"3.10.x und 3.11.x, schließt 3.12 aus
ODER`“python=3.103.11”`

2. Aktivieren und Deaktivieren

Beim Aktivieren wird der Pfad der Umgebung an den Anfang der Systemumgebungsvariable PATH gestellt:

# Umgebung aktivieren
conda activate ml_projekt

# Eingabeaufforderung zeigt den aktiven Namen:
# (ml_projekt) user@workstation:~$

# Zurück zur Basisebene
conda deactivate

Tipp: Wenn das Terminal beim Öffnen nicht automatisch die base-Umgebung laden soll:

conda config --set auto_activate_base false

3. Umgebungen auflisten

conda env list
# oder
conda info --envs

Die aktuell aktive Umgebung ist mit einem Sternchen (*) markiert.

4. Umgebung klonen und umbenennen

# Umgebung duplizieren
conda create --name ml_backup --clone ml_projekt

# Umgebung umbenennen (ab Conda 4.14)
conda rename --name alter_name neuer_name

5. Export und Reproduzierbarkeit

Um eine Umgebung mit Kollegen oder in CI/CD-Pipelines zu teilen:

# Umgebung als YAML exportieren
conda env export --no-builds > environment.yml

# Aus YAML wiederherstellen
conda env create -f environment.yml

6. Umgebung löschen

conda env remove --name ml_backup

Pakete verwalten

1. Installation und Suche

# Paket installieren
conda install pytorch torchvision torchaudio -c pytorch -c nvidia

# Nach Paketen suchen
conda search scikit-learn

2. Aktualisieren und Entfernen

# Einzelnes Paket aktualisieren
conda update numpy

# Alle Pakete in der Umgebung aktualisieren
conda update --all

# Paket entfernen
conda remove scipy

3. Installierte Pakete auflisten

conda list

Schnellübersicht (Cheat Sheet)

# Lebenszyklus von Umgebungen
conda create -n <name> python=3.11     # Umgebung erstellen
conda activate <name>                  # Umgebung aktivieren
conda deactivate                       # Umgebung verlassen
conda env list                         # Alle Umgebungen anzeigen
conda env remove -n <name>             # Umgebung löschen

# Reproduzierbarkeit
conda env export --no-builds > env.yml # Als portables YAML exportieren
conda env create -f env.yml            # Aus YAML wiederherstellen

# Pakete
conda install <paket>                  # Paket installieren
conda update <paket>                   # Paket aktualisieren
conda remove <paket>                   # Paket entfernen
conda list                             # Installierte Pakete auflisten
