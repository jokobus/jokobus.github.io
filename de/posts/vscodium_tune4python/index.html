VSCodium optimal für Python konfigurieren

📅 30. May 2026 ⏱️ ~1 Min. Lesezeit (125 Wörter) #IDE #VSCodium #VSCode #Python #Entwicklung

VSCodium ist die datenschutzfreundliche, quelloffene Distribution von VS Code – komplett frei von Microsoft-Telemetrie und Tracking.

Damit Autovervollständigung, Syntax-Highlighting und Dokumentations-Tooltips für Python absolut flüssig laufen, genügen zwei einfache Schritte:

1. Erweiterungen installieren

Öffne den Erweiterungs-Store in der linken Leiste (Strg+Umschalt+X) und installiere:

  • Python (von Microsoft / Open VSX)
  • Pyright (von ms-pyright) – der extrem performante, statische Typ- und Language Server.

2. Benutzer-Einstellungen (settings.json) optimieren

Drücke Strg+Umschalt+P, tippe Preferences: Open User Settings (JSON) ein und füge folgende optimierte Konfiguration ein:

{
  "editor.hover.enabled": "on",
  "editor.hover.delay": 150,
  "editor.parameterHints.enabled": true,
  "editor.suggestOnTriggerCharacters": true,
  "editor.bracketPairs.enabled": true,
  "editor.guides.bracketPairs": "active",
  "editor.suggest.preview": true,
  "editor.inlineSuggest.enabled": true,
  "editor.suggest.showDetails": true,
  "python.analysis.typeCheckingMode": "basic"
}
💡
Ergebnis
Mit diesen Einstellungen reagieren Hover-Vorschauen bereits nach 150 ms, Klammerpaare werden farblich hervorgehoben und Type-Checking warnt dich frühzeitig vor subtilen Typfehlern.
