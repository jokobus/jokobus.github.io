Dieser Spickzettel fasst die zentralen Sprachkonzepte, Syntaxelemente und Datenstrukturen von Java kompakt zusammen – von primitiven Typen bis hin zur objektorientierten Modellierung und dem Collections Framework.

1. Grundlagen

Kompilieren & Ausführen

javac Main.java    # Kompiliert Quelltext in Bytecode (Main.class)
java Main          # Startet die Java Virtual Machine (JVM)

Ein- und Ausgabe (Konsole)

int zahl = 42;
System.out.println("Wert: " + zahl);

Typumwandlung (Type Casting)

int x = 5;
double z = x;        // Widening (automatisch): 5.0
int y = (int) z;     // Narrowing (explizit erforderlich): 5

Strings & Methoden

String vorname = "Ada ";
String nachname = "Lovelace";
String voll = vorname.trim() + " " + nachname; // "Ada Lovelace"
int laenge = voll.length();                   // 12
String gross = voll.toUpperCase();            // "ADA LOVELACE"

2. Kontrollstrukturen

Verzweigungen (if, else if, else)

if (x > y) {
    System.out.println("Größer");
} else if (x == y) {
    System.out.println("Gleich");
} else {
    System.out.println("Kleiner");
}

Ternärer Operator

String status = (x >= 18) ? "Volljährig" : "Minderjährig";

Schleifen

// For-Schleife
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// For-Each über Arrays oder Collections
String[] autos = {"BMW", "Audi", "Porsche"};
for (String auto : autos) {
    System.out.println(auto);
}

// While-Schleife
while (bedingung) {
    // Rumpf
}

3. Methoden & Überladung

Methoden werden in Java stets innerhalb einer Klasse definiert:

public class Rechner {
    // Methodenüberladung: Gleicher Name, unterschiedliche Parameter
    static int addieren(int a, int b) {
        return a + b;
    }

    static double addieren(double a, double b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(addieren(5, 3));       // 8
        System.out.println(addieren(2.5, 1.5));   // 4.0
    }
}

4. Objektorientierung (OOP)

Klassen & Konstruktor

public class Auto {
    private String marke;
    private int baujahr;

    // Konstruktor
    public Auto(String marke, int baujahr) {
        this.marke = marke;
        this.baujahr = baujahr;
    }

    // Getter & Setter (Kapselung)
    public String getMarke() {
        return marke;
    }
}

Vererbung & Polymorphie

class Tier {
    public void lautGeben() {
        System.out.println("Ein Tier gibt Laut");
    }
}

class Hund extends Tier {
    @Override
    public void lautGeben() {
        System.out.println("Wuff!");
    }
}

Interfaces (Schnittstellen)

interface Startbar {
    void starten();
}

class Server implements Startbar {
    @Override
    public void starten() {
        System.out.println("Server hochgefahren.");
    }
}

5. Java Collections Framework

ArrayList (Dynamisches Array)

import java.util.ArrayList;
import java.util.Collections;

ArrayList<String> staedte = new ArrayList<>();
staedte.add("Berlin");
staedte.add("München");
staedte.add("Hamburg");

Collections.sort(staedte); // Alphabetisch sortieren

HashMap (Schlüssel-Wert-Paare)

import java.util.HashMap;

HashMap<String, String> laender = new HashMap<>();
laender.put("DE", "Deutschland");
laender.put("AT", "Österreich");
laender.put("CH", "Schweiz");

String name = laender.get("DE"); // "Deutschland"

6. Ausnahmebehandlung (Exception Handling)

try {
    int ergebnis = 10 / 0;
} catch (ArithmeticException e) {
    System.err.println("Division durch Null abgefangen: " + e.getMessage());
} finally {
    System.out.println("Wird immer ausgeführt (Ressourcenfreigabe).");
}
