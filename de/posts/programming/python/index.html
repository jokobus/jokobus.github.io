Python besticht durch seine intuitive, lesbare Syntax und bildet das Rückgrat moderner Datenwissenschaft, künstlicher Intelligenz (PyTorch, TensorFlow) und wissenschaftlicher Berechnungen. Diese Referenz fasst die Kernkonzepte der Sprache übersichtlich zusammen.

1. Variablen & Grundlegende Datentypen

Python ist dynamisch typisiert und verfügt über automatische Speicherbereinigung (Garbage Collection):

# Ganze Zahlen, Fließkommazahlen, Zeichenketten, Booleans
anzahl = 42
temperatur = 36.8
sprache = "Python 3.12"
aktiv = True

# Dynamische Typabfrage
print(type(anzahl))      # <class 'int'>
print(type(temperatur))  # <class 'float'>

Praxisbeispiele

# Listenoperationen
fruechte = ["Apfel", "Banane", "Kirsche"]
fruechte.append("Orange")
print(fruechte[1:3])  # Slicing: ['Banane', 'Kirsche']

# Dictionaries (Schlüssel-Wert-Paare)
nutzer = {"id": 101, "rolle": "admin", "aktiv": True}
nutzer["email"] = "admin@example.org"

# Mengen (Mengenlehre & schnelle O(1)-Prüfung)
tags_a = {"ki", "robotik", "python"}
tags_b = {"python", "web", "linux"}
schnittmenge = tags_a & tags_b  # {'python'}

3. List- und Dictionary-Comprehensions

Comprehensions ermöglichen die elegante, funktionale Konstruktion von Sequenzen:

# Quadrate gerader Zahlen
quadrate = [x**2 for x in range(10) if x % 2 == 0]
# [0, 4, 16, 36, 64]

# Tausch von Schlüsseln und Werten im Dictionary
lookup = {zeichen: index for index, zeichen in enumerate("ABC")}
# {'A': 0, 'B': 1, 'C': 2}

4. Funktionen & Argumente

# Standardwerte und Typ-Annotationen
def begruessen(name: str, gruss: str = "Hallo") -> str:
    return f"{gruss}, {name}!"

# Variable Argumente (*args, **kwargs)
def protokolliere(*args, **kwargs):
    print("Positionsargumente:", args)
    print("Schlüsselwortargumente:", kwargs)

# Anonyme Lambda-Funktion
quadrieren = lambda x: x ** 2

5. Objektorientierung & Dataclasses

from dataclasses import dataclass

@dataclass
class Vektor2D:
    x: float
    y: float

    def laenge(self) -> float:
        return (self.x**2 + self.y**2) ** 0.5

v = Vektor2D(3.0, 4.0)
print(v.laenge())  # 5.0
