🛠️ Recommended Tools Across Platforms

Once downloaded and extracted, you can import my public key into your favorite email client or cryptographic keyring. Below is an overview of the most trusted open-source and standard software options for your operating system:

🪟

Windows

  • Gpg4win with Kleopatra: The gold-standard suite for Windows. Includes Kleopatra (intuitive GUI certificate manager), Windows Explorer right-click file encryption, and Outlook integration.
  • Mozilla Thunderbird: Features native built-in OpenPGP support without requiring third-party plugins. Easily import keys under Account Settings → End-to-End Encryption.
🤖

Android

  • Thunderbird for Android (or K-9 Mail) + OpenKeychain: Install OpenKeychain to securely hold your keys, then connect it to Thunderbird for Android via the OpenPgp API for automatic one-tap encryption and decryption.
  • FairEmail + OpenKeychain: Another top privacy-focused Android email client with seamless OpenKeychain support.
🐧

Linux

  • GnuPG (gpg): Standard CLI tool present in virtually all distributions for high-speed key management and scripting.
  • GUI Keyrings: Kleopatra (KDE) or Seahorse (GNOME Passwords & Keys) for graphical key import and validation.
  • Thunderbird & Evolution: Native PGP email handling across modern Linux desktop environments.
🍏

macOS & iOS

  • macOS — GPG Suite: The premier macOS bundle offering GPG Keychain, Apple Mail integration, and Finder right-click encryption.
  • macOS — Thunderbird: Fully supported native OpenPGP email client.
  • iOS — Canary Mail: Modern iOS email app with built-in PGP key management and encryption.
  • iOS — PGPro: Standalone iOS utility for encrypting/decrypting text and file attachments.
💡
First time using OpenPGP?
The easiest entry point on desktop is Mozilla Thunderbird (available on Windows, Mac, and Linux) or Gpg4win / Kleopatra on Windows. On mobile, pair Thunderbird for Android with OpenKeychain.
