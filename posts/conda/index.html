Why Conda?

Conda is an open-source package management and environment management system designed for scientific computing, machine learning, and multi-language development (Python, R, C/C++, etc.).

Key advantages of Conda include:

  • Isolated Environments: Every project maintains its own isolated dependency sandbox, preventing version conflicts between libraries (e.g. PyTorch 2.x vs TensorFlow 2.x).
  • Binary Non-Python Dependencies: Unlike pip, which primarily manages Python wheels and packages, Conda can install compiled system libraries (such as CUDA runtimes, cuDNN, OpenBLAS, Graphviz, and HDF5) directly into your environment without requiring root/sudo privileges.
  • Cross-Platform Consistency: Ensures identical dependency resolution across Linux, macOS, and Windows.

Installation: Miniforge vs. Anaconda

While full Anaconda includes a large bundle of pre-installed GUI tools and packages, the recommended modern standard is Miniforge. Miniforge is a minimalist, community-driven installer pre-configured with conda-forge as the default channel (avoiding commercial licensing restrictions of Anaconda’s default channel).

Linux / macOS

Download and run the Miniforge installation script:

# Download installer script
wget https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh

# Run installer (follow prompts, default path ~/.miniforge3 is recommended)
bash Miniforge3-Linux-x86_64.sh

Restart your terminal or reload your shell profile (source ~/.bashrc or source ~/.zshrc).

Windows

Download the executable installer Miniforge3-Windows-x86_64.exe from the conda-forge releases and run the setup wizard.

Verify Installation

conda --version
conda info

Custom Configuration (.condarc)

Conda can be customized globally (~/.condarc) or per-project. For example, to specify custom directory paths for environments and downloaded packages:

# ~/.condarc
envs_dirs:
  - ~/miniconda3/envs
  - /data/shared/conda/envs

pkgs_dirs:
  - ~/miniconda3/pkgs
  - /data/shared/conda/pkgs

channels:
  - conda-forge

To inspect your active runtime configuration:

conda config --show

Managing Environments

1. Create a New Environment

Always specify a project name and desired Python version when creating an environment:

# Create environment with a specific Python version
conda create --name ml_project python=3.11

# Create environment with initial packages
conda create --name cv_project python=3.10 numpy opencv matplotlib

2. Activate and Deactivate

When an environment is activated, Conda prepends its binary folder to your system PATH:

# Activate target environment
conda activate ml_project

# Terminal prompt reflects the active environment:
# (ml_project) user@workstation:~$

# Deactivate back to base
conda deactivate

Tip: If you prefer your terminal not to automatically activate the base environment on launch, run:

conda config --set auto_activate_base false

3. List Environments

conda env list
# or
conda info --envs

The active environment is indicated with an asterisk (*).

4. Clone and Rename Environments

To duplicate an existing environment:

conda create --name ml_backup --clone ml_project

To rename an environment (Conda 4.14+):

conda rename --name old_name new_name

5. Export and Recreate (Reproducibility)

To share your exact environment state with colleagues or CI/CD pipelines:

# Export environment definition to YAML
conda env export --no-builds > environment.yml

# Recreate environment from YAML
conda env create -f environment.yml

6. Delete an Environment

conda env remove --name ml_backup

Managing Packages

1. Install and Search

# Install a package from conda-forge
conda install pytorch torchvision torchaudio -c pytorch -c nvidia

# Search for available package versions
conda search scikit-learn

2. Update and Remove

# Update a single package
conda update numpy

# Update all packages in the active environment
conda update --all

# Remove a package and its orphaned dependencies
conda remove scipy

3. List Installed Packages

conda list

Essential Cheat Sheet

# Environment Lifecycle
conda create -n <name> python=3.11    # Create new environment
conda activate <name>                 # Activate environment
conda deactivate                      # Exit environment
conda env list                        # Show all environments
conda env remove -n <name>            # Delete environment

# Reproducibility
conda env export --no-builds > env.yml # Export to portable YAML
conda env create -f env.yml           # Recreate from YAML

# Packages
conda install <pkg>                   # Install package
conda update <pkg>                    # Update package
conda remove <pkg>                    # Remove package
conda list                            # List installed packages
