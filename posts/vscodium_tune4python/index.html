Tune VSCodium for Python

📅 30. May 2026 ⏱️ ~1 min read (107 words) #IDE #VSCodium #Python

VSCodium is the privacy-focused, open-source binary release of VS Code, free of Microsoft telemetry.

However, out of the box, VSCodium requires a couple of extension and configuration tweaks to enable seamless autocomplete, syntax highlighting, and hover documentation for Python. Follow these two simple steps to optimize your setup:

1. Install Extensions

Install the

  • Python and
  • Pyright (by ms-pyright)

Extensions via the Extensions Store at the left, vertical bar in VSCodium.

2. Tweak your settings.json

In the search bar enter: > settings.json. Choose the User Settings.json and paste:

{
  "editor.hover.enabled": true,
  "editor.hover.delay": 150,
  "editor.parameterHints.enabled": true,
  "editor.suggestOnTriggerCharacters": true,
  "editor.bracketPairs.enabled": true,
  "editor.guides.bracketPairs": "active",
  "editor.suggest.preview": true,
  "editor.suggest.showDetails": true,
  "python.analysis.typeCheckingMode": "basic"
}
