Introduction

In our previous article, Backpropagation in Standard Calculus , we derived the gradient update equations using scalar notation. While standard calculus builds an intuitive understanding of how error flows through individual connections, writing code using scalar loops is computationally inefficient.

In practice, modern machine learning libraries (like PyTorch or TensorFlow) compute updates over entire layers simultaneously using Matrix Calculus and linear algebra routines optimized for GPUs.

This article formalizes backpropagation in vector and matrix notation.

Mathematical Conventions & Notation

We treat all vectors as column vectors unless transposed.

For a network with $L$ layers:

  • $l \in \{1, 2, \dots, L\}$ denotes the layer index ($l=0$ is the input layer).
  • $n_l$ is the number of neurons in layer $l$.
  • $\mathbf{x} = \mathbf{a}^{(0)} \in \mathbb{R}^{n_0 \times 1}$ is the input vector.
  • $\mathbf{W}^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}$ is the weight matrix for layer $l$, where entry $W_{ij}^{(l)}$ connects unit $j$ in layer $l-1$ to unit $i$ in layer $l$.
  • $\mathbf{b}^{(l)} \in \mathbb{R}^{n_l \times 1}$ is the bias vector for layer $l$.
  • $\mathbf{z}^{(l)} \in \mathbb{R}^{n_l \times 1}$ is the pre-activation linear combination.
  • $\mathbf{a}^{(l)} \in \mathbb{R}^{n_l \times 1}$ is the post-activation vector.

Side Note: The Hadamard Product ($\odot$)

When working with matrix calculus in neural networks, we frequently encounter element-wise operations. The Hadamard Product (also called the entrywise or element-wise product), denoted by $\odot$, multiplies corresponding elements of two matrices or vectors of identical dimensions.

Given two vectors $\mathbf{u}, \mathbf{v} \in \mathbb{R}^{n \times 1}$:

$$\mathbf{u} \odot \mathbf{v} = \begin{bmatrix} u_1 \\ u_2 \\ \vdots \\ u_n \end{bmatrix} \odot \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix} = \begin{bmatrix} u_1 v_1 \\ u_2 v_2 \\ \vdots \\ u_n v_n \end{bmatrix}$$

Unlike standard matrix multiplication ($\mathbf{A} \mathbf{B}$), which sums dot products across rows and columns, the Hadamard product keeps the dimensions unchanged ($n \times 1$). We use it when applying nonlinear element-wise derivative functions $\sigma'(\mathbf{z})$ to error vectors.

Vectorized Forward Pass

For any layer $l \in \{1, \dots, L\}$, the forward pass calculations are expressed as:

$$\mathbf{z}^{(l)} = \mathbf{W}^{(l)} \mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$$$$\mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)})$$

where $\sigma(\cdot)$ represents an element-wise activation function (e.g., Sigmoid, ReLU).

Loss Function

Using the Mean Squared Error (MSE) loss over target vector $\mathbf{t} \in \mathbb{R}^{n_L \times 1}$ and network output $\mathbf{y} = \mathbf{a}^{(L)}$:

$$E = \frac{1}{2} \Vert{}\mathbf{a}^{(L)} - \mathbf{t}\Vert{}^2 = \frac{1}{2} \sum_{i=1}^{n_L} \left(a_i^{(L)} - t_i\right)^2$$

Vectorized Backpropagation

To update parameters via gradient descent, we need two target derivatives for each layer $l$:

  1. $\frac{\partial E}{\partial \mathbf{W}^{(l)}}$ (a matrix of shape $n_l \times n_{l-1}$)
  2. $\frac{\partial E}{\partial \mathbf{b}^{(l)}}$ (a vector of shape $n_l \times 1$)

1. The Error Vector ($\boldsymbol{\delta}^{(l)}$)

We define the layer error vector $\boldsymbol{\delta}^{(l)}$ as the gradient of the loss with respect to the unactivated weighted input $\mathbf{z}^{(l)}$:

$$\boldsymbol{\delta}^{(l)} \equiv \frac{\partial E}{\partial \mathbf{z}^{(l)}} = \begin{bmatrix} \frac{\partial E}{\partial z_1^{(l)}} \\ \vdots \\ \frac{\partial E}{\partial z_{n_l}^{(l)}} \end{bmatrix} \in \mathbb{R}^{n_l \times 1}$$

2. Output Layer Error ($\boldsymbol{\delta}^{(L)}$)

Applying the multivariable chain rule to the final layer $L$:

$$\boldsymbol{\delta}^{(L)} = \left( \frac{\partial \mathbf{a}^{(L)}}{\partial \mathbf{z}^{(L)}} \right)^T \frac{\partial E}{\partial \mathbf{a}^{(L)}}$$

Since $\frac{\partial E}{\partial \mathbf{a}^{(L)}} = (\mathbf{a}^{(L)} - \mathbf{t})$ and the Jacobian $\frac{\partial \mathbf{a}^{(L)}}{\partial \mathbf{z}^{(L)}}$ is a diagonal matrix of activation derivatives $\operatorname{diag}(\sigma'(\mathbf{z}^{(L)}))$, this simplifies directly via the Hadamard product:

$$\boldsymbol{\delta}^{(L)} = (\mathbf{a}^{(L)} - \mathbf{t}) \odot \sigma'(\mathbf{z}^{(L)})$$

3. Layer Recurrence Relation ($\boldsymbol{\delta}^{(l)}$ from $\boldsymbol{\delta}^{(l+1)}$)

To propagate the error backwards from layer $l+1$ to layer $l$, we apply the chain rule:

$$\boldsymbol{\delta}^{(l)} = \frac{\partial E}{\partial \mathbf{z}^{(l)}} = \left( \frac{\partial \mathbf{z}^{(l+1)}}{\partial \mathbf{z}^{(l)}} \right)^T \frac{\partial E}{\partial \mathbf{z}^{(l+1)}}$$

Given that $\mathbf{z}^{(l+1)} = \mathbf{W}^{(l+1)} \mathbf{a}^{(l)} + \mathbf{b}^{(l+1)}$ and $\mathbf{a}^{(l)} = \sigma(\mathbf{z}^{(l)})$, taking the Jacobian matrix $\frac{\partial \mathbf{z}^{(l+1)}}{\partial \mathbf{z}^{(l)}}$ yields $\mathbf{W}^{(l+1)} \operatorname{diag}(\sigma'(\mathbf{z}^{(l)}))$. Transposing and multiplying gives:

$$\boldsymbol{\delta}^{(l)} = \left( (\mathbf{W}^{(l+1)})^T \boldsymbol{\delta}^{(l+1)} \right) \odot \sigma'(\mathbf{z}^{(l)})$$

This recursive relation allows computing all errors $\boldsymbol{\delta}^{(l)}$ starting from $L$ down to $1$.

4. Parameter Gradients

With $\boldsymbol{\delta}^{(l)}$ computed, parameter derivatives are evaluated as:

$$\frac{\partial E}{\partial \mathbf{W}^{(l)}} = \boldsymbol{\delta}^{(l)} (\mathbf{a}^{(l-1)})^T$$$$\frac{\partial E}{\partial \mathbf{b}^{(l)}} = \boldsymbol{\delta}^{(l)}$$

Detailed Example: Unrolling Gradients to Layer 1

Consider a 3-layer neural network ($L=3$) with input vector $\mathbf{x} = \mathbf{a}^{(0)}$.

[ Input: x ] ---> [ Layer 1: W(1) ] ---> [ Layer 2: W(2) ] ---> [ Layer 3: W(3) ] ---> [ Output: y = a(3) ]

We want to find the exact unrolled gradient expression for the first weight matrix $\mathbf{W}^{(1)}$ in terms of the initial input $\mathbf{x}$, weights, activation derivatives, and error target $\mathbf{t}$.

Step 1: Compute Output Error $\boldsymbol{\delta}^{(3)}$

$$\boldsymbol{\delta}^{(3)} = (\mathbf{a}^{(3)} - \mathbf{t}) \odot \sigma'(\mathbf{z}^{(3)})$$

Step 2: Propagate to Layer 2 Error $\boldsymbol{\delta}^{(2)}$

Substitute $\boldsymbol{\delta}^{(3)}$ into the recurrence formula:

$$\boldsymbol{\delta}^{(2)} = \left( (\mathbf{W}^{(3)})^T \boldsymbol{\delta}^{(3)} \right) \odot \sigma'(\mathbf{z}^{(2)})$$$$\boldsymbol{\delta}^{(2)} = \left( (\mathbf{W}^{(3)})^T \left[ (\mathbf{a}^{(3)} - \mathbf{t}) \odot \sigma'(\mathbf{z}^{(3)}) \right] \right) \odot \sigma'(\mathbf{z}^{(2)})$$

Step 3: Propagate to Layer 1 Error $\boldsymbol{\delta}^{(1)}$

Substitute $\boldsymbol{\delta}^{(2)}$ into the recurrence formula:

$$\boldsymbol{\delta}^{(1)} = \left( (\mathbf{W}^{(2)})^T \boldsymbol{\delta}^{(2)} \right) \odot \sigma'(\mathbf{z}^{(1)})$$

Substituting the full expression for $\boldsymbol{\delta}^{(2)}$ yields:

$$\boldsymbol{\delta}^{(1)} = \left( (\mathbf{W}^{(2)})^T \left[ \left( (\mathbf{W}^{(3)})^T \left[ (\mathbf{a}^{(3)} - \mathbf{t}) \odot \sigma'(\mathbf{z}^{(3)}) \right] \right) \odot \sigma'(\mathbf{z}^{(2)}) \right] \right) \odot \sigma'(\mathbf{z}^{(1)})$$

Step 4: Final Unrolled Gradient for $\mathbf{W}^{(1)}$

Using $\frac{\partial E}{\partial \mathbf{W}^{(1)}} = \boldsymbol{\delta}^{(1)} (\mathbf{a}^{(0)})^T$ where $\mathbf{a}^{(0)} = \mathbf{x}$:

$$\frac{\partial E}{\partial \mathbf{W}^{(1)}} = \left( \left( (\mathbf{W}^{(2)})^T \left( (\mathbf{W}^{(3)})^T \left[ (\mathbf{a}^{(3)} - \mathbf{t}) \odot \sigma'(\mathbf{z}^{(3)}) \right] \odot \sigma'(\mathbf{z}^{(2)}) \right) \right) \odot \sigma'(\mathbf{z}^{(1)}) \right) \mathbf{x}^T$$
