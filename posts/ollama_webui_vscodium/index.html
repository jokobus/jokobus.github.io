Deploy local AI via Ollama, Open-WebUI and VSCode/VSCodium

A short guide to installing Ollama completely locally, serving it via Open-WebUI, and integrating it as an AI chat and autocomplete agent in VSCode and/or VSCodium.

This is a guide how to install ollama on Linux and serve it to a localhost WebUI (no exposure to the internet) and use Ollama as a Chat Agent in VSCodium.

  • no root / sudo required
  • no proxy server, only conda and python
  • in the following replace USERNAME with your actual username

Install Ollama

Create the Directory structure

mkdir -p /home_local/$USER/ollama/{bin,lib,logs,models,webui}

  • bin/: Stores the Ollama executable.
  • lib/: Holds necessary libraries and dependencies.
  • logs/: Keeps tracking and server logs.
  • models/: Stores downloaded LLMs (Llama, Mistral, etc.).
  • webui/: Reserved for the frontend user interface.

Download and Move the Binary

# Download the latest binary
curl -L https://ollama.com/download/ollama-linux-amd64 -o /home_local/$USER/ollama/bin/ollama

# Make it executable
chmod +x /home_local/$USER/ollama/bin/ollama

Add paths to bashrc

nano ~/.bashrc

Paste: export PATH=/home_local/$USER/ollama/bin:$PATH export LD_LIBRARY_PATH=/home_local/$USER/ollama/lib:$LD_LIBRARY_PATH export OLLAMA_MODELS=/home_local/$USER/ollama/models

Then: source ~/.bashrc

Start the Ollama Server

nohup ollama serve > /home_local/$USER/ollama/logs/server.log 2>&1 & ollama run qwen3-coder:30b

This will download and initialize qwen3-coder:30b and might take a while. Finally, you can test it by giving it a prompt directly in the terminal.

Install Open-WebUI

It is possible to deploy the ollama chats to a local web user interface on http://localhost:8080. For that we need a php, apache or python proxy. In the following we use a simple python proxy.

Create conda environment (optional)

conda create –name ollama_webui python=3.11 -y conda activate ollama_webui conda install pip

Install Open-WebUI

python -m pip install open-webui

You can test it by

open-webui serve

Open http://localhost:8080 in your browser (e.g. firefox) and create a new account. It is 100% on your own PC. Test chatting with qwen3-coder:30b.

Automate the Ollama startup

We want to automatically start the ollama server and webui at each boot.

Create a new startup script

nano /home_local/$USER/ollama/start_ollama_webui.sh

#!/bin/bash

# 1. Load your profile environment variables (for Ollama paths)
source ~/.bashrc

# 2. Start the Ollama server in the background if it isn't running
if ! pkill -0 ollama; then
    nohup ollama serve > /home_local/$USER/ollama/logs/ollama.log 2>&1 &
    sleep 3 # Give it a moment to initialize
fi

# 3. Bind Open WebUI strictly to localhost only and run it
export HOST=127.0.0.1
export PORT=8080

# Initialize Conda for non-interactive shell execution
eval "$(/home_local/$USER/bin/Miniforge/bin/conda shell.bash hook)"
# (Note: If you use Anaconda or Miniconda instead of Miniforge, change 'Miniforge' to 'miniconda3' or 'anaconda3' above)

conda activate ollama_webui
nohup open-webui serve > /home_local/$USER/ollama/logs/ollama_webui.log 2>&1 &

echo "Ollama started successfully!"

Create a cronjob to automatically execute start_ollama_webui.sh at boot.

crontab -e

(If you use it for the first time, choose nano as your editor, it’s the easiest one)

Add the following line to the bottom of the file:

@reboot /home_local/$USER/ollama/start_ollama_webui.sh

Hit Ctrl+X and save yes.

The cronjob will trigger the startup of the ollama server at the next boot. You can also start it up manually in the terminal with:

bash /home_local/$USER/ollama/start_ollama_webui.sh

Connect Ollama to VSCodium

Using the built in Github Copilot requires to you to sign in to Github, even though you are using a local AI model. Therefore we use the popular alternative, called Continue. It is a VSCode/VSCodium extension available on the official Marketplace.

Install Continue

  1. Go to extensions (left sidebar)
  2. Search for Continue
  3. Install & Trust Authors

Configure Continue

  1. Click on the Continue Button (left sidebar)
  2. Click on Config and open the Main Config. This will open a yaml config file.
  3. Paste:
name: VSCodium Setup
version: 1.0.0
schema: v1

models:
  # Automatically pull all your downloaded Ollama models for Chat/Edit
  - name: Ollama Autodetect
    provider: ollama
    model: AUTODETECT
    roles:
      - chat
      - edit
      - apply

  # The fast ghost-text autocomplete
  - name: Qwen 2.5 Coder 7B (Autocomplete)
    provider: ollama
    model: qwen2.5-coder:7b
    roles:
      - autocomplete
  # Use qwen2.5-coder:1.5b instead, if your hardware is not so strong

tabAutocompleteOptions:
  debounceDelay: 100        # Lowers wait time before the model triggers (default is 250ms)
  maxPromptTokens: 2048     # Limits how much background code is read, massively speeding up execution

Next, you can try chatting in the sidebar and wait for auto-completion directly in the text editor.
