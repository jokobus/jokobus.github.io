1. Creating Content & Page Bundles

Smidr embraces Hugo Leaf Bundles. Instead of scattering assets and translations across separate folders, keep every article self-contained:

hugo new posts/autonomous-navigation/index.en.md

This creates a tidy directory structure where your English draft, German translation, companion .bib bibliography, and images live side-by-side:

content/posts/autonomous-navigation/
├── index.en.md        <-- English article
├── index.de.md        <-- German article
├── references.bib     <-- BibTeX references
└── images/            <-- Local diagrams and charts
    └── trajectory.svg

Both files link together seamlessly by sharing the same translationKey in their frontmatter:

---
title: "Autonomous Navigation"
translationKey: "autonomous-navigation"
---

3. Theme Color Palettes & “Farbverlauf” (Gradient)

Smidr features configurable color palettes and a glowing “Farbverlauf” gradient system. You can configure them in config/_default/params.yaml:

# Supported palettes: "cyber" (default/recommended: blue-to-red sweep), "magenta-violet", "neon", "aurora", "sunset", "minimal"
palette: "cyber"

# Farbverlauf toggle:
# true  = with "Farbverlauf" (vibrant magenta-to-violet gradient buttons, glowing borders, and accented headings)
# false = without "Farbverlauf" (clean, solid modern cyberpunk colors with flat buttons)
gradient: true
  • Vibrant Gradient (gradient: true): Buttons, interactive tabs, active pills, and category tags shine with a modern magenta-to-violet transition that catches the eye without disturbing readability.
  • Solid Palette (gradient: false): Crisp, high-contrast monochrome and neon tones for a minimal engineering look.

4. LaTeX Mathematics (KaTeX)

Smidr includes high-performance client-side KaTeX typesetting:

  • Inline formulas: Enclose equations in single dollar signs $f(x) = \sigma(W x + b)$ to render $f(x) = \sigma(W x + b)$.
  • Display blocks: Enclose equations in double dollar signs $$...$$ or \[...\]:
$$\mathcal{L}_{PID}(t) = K_p e(t) + K_i \int_0^t e(\tau) d\tau + K_d \frac{de(t)}{dt}$$

Multiline alignment using LaTeX environments:

$$\begin{aligned} \dot{x}_1 &= x_2 \\ \dot{x}_2 &= -\frac{k}{m} x_1 - \frac{c}{m} x_2 + \frac{1}{m} u(t) \end{aligned}$$

5. Code Blocks with One-Click Copy

Standard Markdown code blocks automatically feature syntax highlighting, language badges, and an instant copy button:

    let gain = 1.45;
    gain * error
}

12. Academic Citations & BibTeX Bibliography Engine
Smidr features a native client-side bibliography engine:
  1. Automatic .bib Loading: Place references.bib inside your post directory. Smidr automatically detects, parses, and displays references when bib_auto_load: true is set.
  2. In-Text Citation: Reference keys anywhere in your text using {{< cite "key" >}} or {{< cite "key1,key2" >}}.
  3. Citation Popovers: Hovering over any citation badge reveals an instant bibliographic card with author, title, journal, and year.
  4. Direct BibTeX Export: Every bibliographic entry features a one-click Copy BibTeX button and direct DOI/URL links.
Example Citations:
As shown in Kalman’s seminal paper [kalman1960]
and foundational feedback theory [astrom2010]
, optimal estimation requires minimal variance guarantees. Robot kinematics are comprehensively discussed in Craig [craig2005]
.

    13. Interactive Knowledge Graph (Digital Garden)
    Connect your thoughts visually! Setting gardenGraph: true in your frontmatter or params.yaml renders an interactive physics-simulated network graph at the bottom of the page or on the homepage. Readers can zoom, pan, hover to highlight clusters, and click nodes to navigate directly between interconnected ideas.
    14. Contextual Backlinks
    When showBacklinks: true is configured, Smidr automatically discovers and displays all incoming references from other articles in your knowledge base, turning your blog into a self-organizing digital garden.

    16. Command Palette & Instant Fuzzy Search
    Press Ctrl + K (or Cmd + K on macOS), or click the search button in the navigation bar. A cyberpunk modal appears instantly, allowing real-time fuzzy querying across article titles, headings, tags, and content snippets without any backend server.

    21. AI Transparency & Provenance Badges
    Smidr champions transparent scientific communication. Add provenance metadata to your frontmatter:
    used_ai: true
original_language: "de"
original_post_path: "/de/posts/mein-original/"
ai_model: "Claude 3.7 / Ollama"

    Smidr automatically renders an unobtrusive provenance notice informing readers whether a post was human-authored, translated, or refined with AI assistance.
