Setting Up Microsoft OneDrive on Manjaro & Arch Linux

A complete, step-by-step guide to installing, configuring, and automating Microsoft OneDrive cloud synchronization on Manjaro and Arch Linux using onedrive-abraunegg.

If you work in a dual-boot setup with Windows or rely on Microsoft 360 for university, research, or work, having native access to your Microsoft OneDrive cloud storage on Linux is essential.

While Microsoft does not provide an official OneDrive client for Linux desktops, the open-source community client developed by abraunegg is extraordinarily mature, stable, and fast. It supports bi-directional synchronization, real-time file monitoring via inotify, selective syncing, and clean systemd user service integration.

Here is how to set it up effortlessly on Manjaro and Arch Linux.

1. Installation

On Manjaro and Arch Linux, the precompiled client is available directly from the official extra repository:

sudo pacman -S onedrive

If you prefer compiling the latest bleeding-edge release from source, you can build it via the AUR using pamac or yay:

pamac build onedrive-abraunegg

2. Initial Setup & Microsoft OAuth Authentication

To authorize the client with your Microsoft account, run the command once in your terminal:

onedrive

The application will print an instruction message containing a long Microsoft login URL:

Authorize this client by visiting:

https://login.microsoftonline.com/common/oauth2/v2.0/authorize?client_id=...
  1. Copy the full link and open it in your browser.
  2. Log into your Microsoft account (personal, university, or business account).
  3. After granting consent, your browser will redirect to a blank white page starting with https://login.microsoftonline.com/common/oauth2/nativeclient?code=....
  4. Copy the entire URL of this blank page from your browser’s address bar.
  5. Paste it back into your terminal prompt and press Enter.

Once authenticated, the client will verify the token and display your available cloud storage quota.

3. Configuration & Selective Sync (Optional)

By default, the client synchronizes everything to ~/OneDrive. If you only want to sync specific directories (e.g., your documents and notes while omitting massive media folders), you can define a selective sync list.

Create the local configuration directory:

mkdir -p ~/.config/onedrive

Create a sync_list file:

nano ~/.config/onedrive/sync_list

Add the folders or file patterns you wish to sync (one per line, starting with / relative to your OneDrive root):

/Documents
/Notes
/Research
/Code
!/Documents/LargeArchives

Save with Ctrl+O and exit with Ctrl+X. You can test your sync list without downloading anything by running a dry run:

onedrive --synchronize --dry-run

4. Enabling Background Sync via Systemd

To ensure your files are automatically synchronized in the background whenever you log into Manjaro, enable the user-level systemd service:

systemctl --user enable --now onedrive

Verify that the service is running properly:

systemctl --user status onedrive

5. Checking Sync Status

Whenever you want to verify that all your files are fully synchronized or check remaining cloud storage:

onedrive --display-sync-status

To force an immediate manual synchronization:

onedrive --synchronize

With this lightweight service running quietly in the background, your documents stay synchronized across Windows, Linux, and mobile devices without taxing your CPU or battery life.
