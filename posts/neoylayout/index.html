Ergonomic Typing with Neo Layout (Bone Variant)

An introduction to the ergonomic Neo Keyboard Layout (Bone variant) for faster, healthier programming and LaTeX typing.

This is a concise guide to the essentials of the Neo Keyboard Layout variant Bone for faster, healthier typing and streamlined mathematical notation.

Windows

To use it on Windows follow these steps.

Install

  • Copy the kbdbone.dll file in System32 to C:\Windows\System32 and the one in SysWOW64 to C:\Windows\SysWOW64 respectively. Grant access rights. (On 64-bit Windows you have to copy it with a 64-bit Programm, best by the Windows Explorer)

  • Execute the kbdneo_win10_install.reg file, which will add the layout to the registry for you. Again, grant access.

  • Reboot your system

  • In System Settings under Time&Language/Language choose the System Language and choose Bone as your keyboard layout.

  • At each boot: execute reneo.exe (e.g. via Tasksheduler)

Uninstall

The uninstallation is best to be performed in reversed order of the installation

  • Stop reneo.exe

  • In the System Settings, remove the layout from the list

  • Execute the Registry uninstall file kbd_win10_uninstall.reg

  • Delete both kbdneo.dll files from C:\Windows\System32 and _C:\Windows\SysWOW64_s

  • Reboot your computer

Linux Setup

Neo Bone is already natively integrated into the standard Linux keyboard configuration database (xkeyboard-config). You do not need to compile or download external drivers.

Method 1: Via Desktop System Settings (Recommended)

Configuring Bone directly through your desktop environment settings ensures the layout persists cleanly across restarts:

KDE Plasma (e.g. Manjaro KDE, Kubuntu, Fedora KDE)

  1. Open System Settings $ ightarrow$ Input Devices $ ightarrow$ Keyboard.
  2. Switch to the Layouts tab.
  3. Click the Add… button (+).
  4. Set Language to German and scroll down the variant list to select German (Bone).
  5. Click Add and use the arrow buttons to move Bone to the top of your list (or configure a layout switching shortcut).
  6. Click Apply in the bottom right corner.

GNOME (e.g. Ubuntu, Fedora Workstation)

  1. Open Settings $ ightarrow$ Keyboard.
  2. Under Input Sources, click Add Input Source (+).
  3. Click the three vertical dots (More…), search for Bone, and select German (Bone).
  4. Add the layout and move it to the top position.

XFCE (e.g. Manjaro XFCE, Xubuntu)

  1. Open Settings $ ightarrow$ Keyboard $ ightarrow$ Layout tab.
  2. Uncheck Use system defaults.
  3. Click Add, select Language German, and choose variant German (Bone).
  4. Move Bone to the top.

Method 2: Fast Terminal Switching (setxkbmap)

If you want to quickly toggle between standard QWERTZ and Bone via command line:

# Switch immediately to Neo Bone:
setxkbmap -layout de -variant bone

# Switch back to standard German QWERTZ:
setxkbmap -layout de

You can add practical aliases to your ~/.bashrc:

alias setbone="setxkbmap -layout de -variant bone"
alias setde="setxkbmap -layout de"

Apply Layout to the Linux Login Screen (SDDM, GDM, LightDM)

If you use a display manager, you might notice that after setting Bone in your user session, the initial login screen still falls back to the default QWERTZ or QWERTY layout. 👉 Configuring Ergonomic Keyboard Layouts on the Linux Login Screen (SDDM, GDM, LightDM)

Learn the Layout

Well, the beginning will be tough, but definitely worth it.

For the start, I recommend tipp10 which has the option to learn bone in the online-version (but not in the desktop version). That is definitely a good start for the first few days, where you have to look up every second character.

Afterwards you can set the keymapping of the first layer as your Desktop background image, so you can always look characters up.

Good luck and stay with it!
