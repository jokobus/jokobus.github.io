Ergonomic Typing with Neo Layout (Bone Variant)

📅 16. Jun 2025 ⏱️ ~2 min read (338 words) #Linux #Windows #LaTeX #Ergonomics
📑 Table of Contents ▾

This is a concise guide to the essentials of the Neo Keyboard Layout variant Bone for faster, healthier typing and streamlined mathematical notation.

Windows

To use it on Windows follow these steps.

Install

  • Copy the kbdbone.dll file in System32 to C:\Windows\System32 and the one in SysWOW64 to C:\Windows\SysWOW64 respectively. Grant access rights. (On 64-bit Windows you have to copy it with a 64-bit Programm, best by the Windows Explorer)

  • Execute the kbdneo_win10_install.reg file, which will add the layout to the registry for you. Again, grant access.

  • Reboot your system

  • In System Settings under Time&Language/Language choose the System Language and choose Bone as your keyboard layout.

  • At each boot: execute reneo.exe (e.g. via Tasksheduler)

Uninstall

The uninstallation is best to be performed in reversed order of the installation

  • Stop reneo.exe

  • In the System Settings, remove the layout from the list

  • Execute the Registry uninstall file kbd_win10_uninstall.reg

  • Delete both kbdneo.dll files from C:\Windows\System32 and _C:\Windows\SysWOW64_s

  • Reboot your computer

Linux

In most Distro’s you can choose Neolayout Bone in your System Settings.

If not (or if it get’s reset at every reboot) you can use the following command:

setxkbmap -layout de -variant bone

or set it back to the normal german

setxkbmap -layout de

I found that it is most convenient to add aliases to my bashrc

nano ~/.bashrc

add the lines (doesn’t matter where, e.g. put it in the first lines)

alias setbone=setxkbmap -layout de -variant bone
alias lfshgjf=setxkbmap -layout de -variant bone
alias setde=setxkbmap -layout de
alias lfswf=setxkbmap -layout de

Finally source the bashrc

source ~/.bashrc

Learn the Layout

Well, the beginning will be tough, but definitely worth it.

For the start, I recommend tipp10 which has the option to learn bone in the online-version (but not in the desktop version). That is definitely a good start for the first few days, where you have to look up every second character.

Afterwards you can set the keymapping of the first layer as your Desktop background image, so you can always look characters up.

Good luck and stay with it!
