Configuring Ergonomic Keyboard Layouts (Neo/Bone) on the Linux Login Screen (SDDM, GDM, LightDM)

How to make ergonomic keyboard layouts like Neo 2 and Bone persistent on the Linux login screen across KDE Plasma (SDDM), GNOME (GDM), and XFCE (LightDM).

When adopting an ergonomic keyboard layout such as Neo 2 or the Bone variant, a common annoyance quickly arises: while the layout works perfectly inside your logged-in desktop environment, the initial display manager login screen still defaults to standard QWERTZ or QWERTY.

Typing complex passwords with muscle memory becomes an immediate frustration if you have to mentally translate keystrokes back to an old layout.

Here is how to cleanly configure your display manager to load Bone or Neo natively before login across KDE Plasma (SDDM), GNOME (GDM), and XFCE (LightDM).

1. KDE Plasma (SDDM)

KDE Plasma provides a built-in mechanism to mirror all current desktop environment regional and input settings directly to SDDM without touching configuration files manually.

Method 1: Sync via KDE System Settings (Recommended)

  1. Open System Settings.
  2. In the top search bar, search for Login Screen (SDDM) (located under Colors & Themes or System Administration).
  3. At the bottom of the window, click the “Apply Plasma Settings…” button.
  4. Check the box for Keyboard layout (and optionally cursor theme or display scaling).
  5. Click Apply and enter your administrator password when prompted.

Method 2: System-Wide Configuration via localectl

If you are setting up a minimal installation or prefer terminal configuration:

sudo localectl set-x11-keymap de pc105 bone

This updates /etc/vconsole.conf and /etc/X11/xorg.conf.d/00-keyboard.conf, which SDDM reads upon startup.

2. GNOME (GDM)

On GNOME (Fedora, Ubuntu, or Arch GNOME), GDM runs as its own system user (gdm) with an independent dconf database.

Method 1: Using GNOME Settings GUI

  1. Open Settings $\rightarrow$ Keyboard.
  2. Ensure German (Bone) or your desired layout is listed under Input Sources.
  3. Go to Settings $\rightarrow$ Region & Language (or System $\rightarrow$ Region & Language depending on GNOME version).
  4. At the top right, click the Login Screen toggle (requires unlocking via your administrator password).
  5. Add the Bone layout to the Login Screen list and move it to the top.

Method 2: Terminal / systemd Configuration

You can configure GDM system-wide using localectl:

sudo localectl set-x11-keymap de pc105 bone

Alternatively, set the GDM dconf key directly:

sudo -u gdm dbus-launch gsettings set org.gnome.desktop.input-sources sources "[('xkb', 'de+bone')]"

3. XFCE (LightDM)

XFCE typically relies on LightDM as its display manager. LightDM defaults to the system-wide X11 keyboard configuration.

Method 1: System-Wide X11 Keymap (localectl)

The cleanest and most robust method for LightDM is setting the keymap through systemd:

sudo localectl set-x11-keymap de pc105 bone

This creates /etc/X11/xorg.conf.d/00-keyboard.conf with:

Section "InputClass"
        Identifier "system-keyboard"
        MatchIsKeyboard "on"
        Option "XkbLayout" "de"
        Option "XkbVariant" "bone"
EndSection

Method 2: LightDM Greeter Hook (Fallback)

If your LightDM greeter does not automatically pick up the X11 keymap, you can execute setxkbmap directly in /etc/lightdm/lightdm.conf:

sudo nano /etc/lightdm/lightdm.conf

Find the [Seat:*] section and add or edit the display-setup-script line:

[Seat:*]
display-setup-script=/usr/bin/setxkbmap -layout de -variant bone

Save and exit (Ctrl+O, Ctrl+X).

Verification

Reboot your computer:

sudo reboot

When the login screen appears, type a few characters into the username or password field. You will be able to type your password naturally using your learned ergonomic muscle memory without any layout switching.
