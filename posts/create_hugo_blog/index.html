How to Create a Blog with Hugo and Smidr (Full Guide)

This is a comprehensive, step-by-step guide on how to create, customize, and publish a modern static website using Hugo and the cyber-clean Smidr theme. Whether you want to host your blog for free on GitHub Pages or deploy it automatically to a self-hosted server, this guide covers everything from initial setup to production publishing.

This is Part 1 of our Hugo series:

  • Part 1 (This Guide): Setup, configuration, Smidr theme, leaf bundles, interactive widgets, and publishing.
  • Part 2: Deploy Hugo on your Homeserver via GitHub Actions — zero-trust automated deployment behind Caddy without opening SSH ports.

Architecture: How Hugo and GitHub Work Together

A Hugo blog setup is clean and modular:

[Local Desktop]
   ├── Content (Markdown)
   ├── Configuration (hugo.yaml)
   └── Themes (Smidr via Git Submodule)
         │
         ├── (Local Preview: hugo server at localhost:1313)
         │
         ▼ (Git Push to Private Source Repo)
[GitHub: hugo-source]
         │
         ▼ (GitHub Actions Build: hugo --minify)
[Deployment Target]
   ├── Option A: GitHub Pages (https://<username>.github.io)
   └── Option B: Private Server / Raspberry Pi via Caddy
  1. Source Repository (website or hugo-source): Stores your Markdown drafts, images, configuration files, and theme submodules. This can be private to keep drafts and unpublished posts confidential.
  2. Compiled Static Output (public/): When Hugo runs, it compiles Markdown and layouts into blazing-fast, static HTML, CSS, and JavaScript.
  3. Deployment Target: Served either directly by GitHub Pages (free, public repository <username>.github.io) or pulled down by your own Linux server using automated pipelines.

Prerequisites

Before beginning, install the required development tools for your platform.

1. Terminal

  • Windows: Use PowerShell 7+ rather than legacy Command Prompt (cmd.exe). You can install or update PowerShell via winget:
    winget install -e --id Microsoft.PowerShell
  • Linux & macOS: Your default terminal (bash or zsh) works out of the box.

2. Git & GitHub

You need a GitHub account and Git installed locally:

  • Windows:
    winget install -e --id Git.Git
    (Optional: Install GitHub Desktop via winget install -e --id GitHub.GitHubDesktop if you prefer a graphical authentication helper).
  • Linux (Debian/Ubuntu):
    sudo apt update && sudo apt install git
  • macOS:
    brew install git

Authenticate your Git installation using an SSH key or GitHub CLI (gh auth login).

Step 1: Install Hugo Extended

💡
Hugo Extended Required
The Extended edition of Hugo is strictly required for the Smidr theme because it uses Hugo’s advanced asset pipeline for Sass/SCSS compilation, CSS minification, and fingerprinting.
  • Windows:
    winget install Hugo.Hugo.Extended
  • macOS (Homebrew):
    brew install hugo
  • Linux: Download the latest extended .deb package or tarball from the Hugo GitHub Releases page:
    hugo version
    Verify that the output displays +extended (e.g. hugo v0.125.0+extended ...).

Step 2: Initialize Your Source Repository

Create your central repository to store your Markdown articles, configuration, and assets.

  1. On GitHub, create a new private repository called website (or hugo-source).
  2. Open your terminal, navigate to your development directory, and clone the empty repository:
    cd "C:/Projects" # or ~/Projects on Linux/macOS
git clone https://github.com/yourusername/website.git
cd website
  3. Initialize a new Hugo site inside the directory:
    hugo new site . --force
    Note: Using . creates the Hugo directory structure directly inside your cloned git repository.

Step 3: Install the Smidr Theme

Smidr is a cyber-clean, dark-aesthetic Hugo theme designed for engineers, researchers, and developers. Key features include:

  • In-Browser Interactive Code Execution: Execute Python and JavaScript directly in the browser using WebAssembly (Pyodide).
  • Bilingual / Multilingual Ready: Side-by-side language switching (.en.md and .de.md).
  • LaTeX / KaTeX Mathematics: Blazing fast rendering for equations ( $$E=mc^2$$).
  • Dynamic Sidebar Filter & Search: Multi-checkbox taxonomy filters with AND/OR match modes, instant sorting, and Cmd+K / Ctrl+K modal search.
  • RSS Feeds with Beautiful XSLT Stylesheets: Clean, readable feeds for browsers and feed readers.

Install Smidr as a Git submodule so you can easily pull upstream updates:

git submodule add https://github.com/jokobus/smidr.git themes/smidr

To update the theme in the future:

git submodule update --remote --merge

Step 4: Configure Hugo and Smidr

Hugo supports both single-file configurations (hugo.yaml) and modular directory configurations (config/_default/). We recommend the modern, clean hugo.yaml format.

Create or update hugo.yaml in your project root (or inside config/_default/hugo.yaml):

baseURL: "https://yourusername.github.io/"
title: "My Tech Logbook"
theme: "smidr"
defaultContentLanguage: "en"
enableRobotsTXT: true

# Multi-output formats (required for Smidr fuzzy search & RSS)
outputs:
  home:
    - HTML
    - RSS
    - JSON # Powers client-side Ctrl+K search
  page:
    - HTML
  section:
    - HTML
    - RSS
  taxonomy:
    - HTML
  term:
    - HTML

# Taxonomies
taxonomies:
  category: "categories"
  tag: "tags"
  archive: "archives"

# Multilingual Configuration
languages:
  en:
    label: "English"
    locale: "en-US"
    weight: 1
    title: "My Tech Logbook"
    menus:
      main:
        - name: "Home"
          identifier: "home"
          url: "/"
          weight: 10
        - name: "Blog"
          identifier: "posts"
          url: "/posts/"
          weight: 20
        - name: "About"
          identifier: "about"
          url: "/about/"
          weight: 30
        - name: "Contact"
          identifier: "contact"
          url: "/contact/"
          weight: 40

  de:
    label: "Deutsch"
    locale: "de-DE"
    weight: 2
    title: "Mein Tech Logbuch"
    menus:
      main:
        - name: "Start"
          identifier: "home"
          url: "/"
          weight: 10
        - name: "Blog"
          identifier: "posts"
          url: "/posts/"
          weight: 20
        - name: "Über mich"
          identifier: "about"
          url: "/about/"
          weight: 30
        - name: "Kontakt"
          identifier: "contact"
          url: "/contact/"
          weight: 40

# Goldmark Markdown & KaTeX Math Parser
markup:
  goldmark:
    renderer:
      unsafe: true
    extensions:
      passthrough:
        enable: true
        delimiters:
          block:
            - ['\[', '\]']
            - ['$$', '$$']
          inline:
            - ['\(', '\)']
            - ['$', '$']
  highlight:
    noClasses: false
    style: "dracula"

Theme Parameters (params.yaml)

Place these parameters in config/_default/params.yaml (or under params: in your hugo.yaml):

author:
  name: "Your Name"
  email: "hello@example.com"

subtitle: "Robotics, Machine Learning & Engineering"
description: "A fast, cyber-clean logbook powered by Hugo and Smidr."
since: 2024

# Features
math: true
showReadingTime: true

social:
  github: "yourusername"

social_media:
  items:
    - enabled: true
      title: "GitHub"
      link: "https://github.com/yourusername"

Configure the Default Post Archetype

To ensure every new post automatically has the correct metadata, edit archetypes/default.md:

---
title: "{{ replace .File.ContentBaseName "-" " " | title }}"
description: ""
translationKey: "{{ replace .File.ContentBaseName "-" " " | title | lower }}"
author: "Your Name"
date: {{ .Date }}
archives: ["{{ dateFormat "2006-01" .Date }}"]
categories: ["Guide"]
tags: []
draft: true
toc: true
---

Step 5: Content Organization with Multilingual Leaf Bundles

The cleanest and most robust way to organize blog articles in Hugo is using Leaf Bundles. Instead of maintaining disjointed content/en/ and content/de/ trees, keep each post’s language files and assets together in a single folder:

content/
├── about.en.md
├── about.de.md
├── contact.en.md
├── contact.de.md
└── posts/
    └── my-first-post/
        ├── index.en.md       <-- English version
        ├── index.de.md       <-- German version
        └── images/           <-- Post-specific diagrams & assets
            └── architecture.svg

1. Create a New Post Bundle

Run the Hugo CLI to generate the bundle:

hugo new posts/my-first-post/index.en.md

2. Add Multilingual Support

To offer the article in German, duplicate index.en.md as index.de.md in the exact same directory:

cp content/posts/my-first-post/index.en.md content/posts/my-first-post/index.de.md

Open index.de.md, translate the content, and ensure both files share the exact same translationKey:

---
title: "Mein erster Beitrag"
translationKey: "my-first-post"
...
---

Hugo and Smidr will automatically link the two versions, enabling the instant language switcher in the header!

Step 6: Supercharge Posts with Smidr Shortcodes

Smidr includes built-in interactive components designed for technical articles:

1. In-Browser Python / WASM Code Runner

Allow readers to run and experiment with Python code right in their browser without installing anything:

{{< code-runner lang="python" title="Interactive Matrix Multiplication" >}}
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
C = np.dot(A, B)

print("Matrix Multiplication Result:")
print(C)
{{< /code-runner >}}

2. Cyber Callouts & Alerts

Highlight key insights or warnings using styled alert boxes:

{{< alert type="tip" title="Pro Tip" >}}
Run `hugo server -D` to preview draft posts locally before pushing to production.
{{< /alert >}}

Supported alert types: info, tip, warning, caution, robotics.

3. Mathematical Typesetting (KaTeX)

Write LaTeX math directly in your Markdown using $$:

$$
f(x) = \frac{1}{1 + e^{-x}}
$$

Step 7: Preview Locally

Start Hugo’s local development server to preview your site with instant live reloading:

hugo server -D

Open http://localhost:1313/ in your browser. Every time you save an edit in your editor, the page reloads automatically in milliseconds.

Step 8: Publishing Your Blog

There are two primary ways to publish your site:

Method A: Automated GitHub Actions CI/CD (Recommended)

Instead of compiling HTML manually on your machine, let GitHub Actions compile and publish your site automatically whenever you push Markdown.

  1. On GitHub, create a public repository named yourusername.github.io.
  2. Generate a Fine-Grained Personal Access Token with read/write permissions for yourusername.github.io.
  3. Add the token to your private website repository secrets as PUBLIC_REPO_TOKEN.
  4. Add the following workflow to .github/workflows/deploy.yml in your source repo:
name: Deploy Hugo Site

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Source & Themes
        uses: actions/checkout@v4
        with:
          submodules: true
          fetch-depth: 0

      - name: Setup Hugo Extended
        uses: peaceiris/actions-hugo@v3
        with:
          hugo-version: 'latest'
          extended: true

      - name: Build Minified Site
        run: hugo --minify

      - name: Push to GitHub Pages Repository
        uses: cpina/github-action-push-to-another-repository@main
        env:
          API_TOKEN_GITHUB: ${{ secrets.PUBLIC_REPO_TOKEN }}
        with:
          source-directory: 'public'
          destination-github-username: 'yourusername'
          destination-repository-name: 'yourusername.github.io'
          user-email: 'hello@example.com'
          target-branch: 'main'

Every git push to your source repository will now automatically compile and deploy your site in under 60 seconds!

Method B: Local Helper Script (Manual Publishing)

If you prefer building locally and pushing to GitHub Pages manually, use a helper script to automate the build and commit steps:

PowerShell Helper (gitcommit.ps1 for Windows):

$message = Read-Host "Enter Commit Message"
if ([string]::IsNullOrWhiteSpace($message)) { $message = "Update blog content" }

Write-Host "--- 1. Pushing Source Repository ---" -ForegroundColor Cyan
git add -A
git commit -m $message
git push origin main

Write-Host "--- 2. Compiling Static Output ---" -ForegroundColor Cyan
hugo --minify

Write-Host "--- 3. Pushing Deployment Repository ---" -ForegroundColor Cyan
Set-Location -Path "public"
git add -A
git commit -m $message
git push origin main

Set-Location -Path ".."
Write-Host "Website successfully deployed!" -ForegroundColor Green

Step 9: Crawlers, SEO & RSS Feeds

1. Robots.txt

When enableRobotsTXT: true is enabled in hugo.yaml, Hugo generates robots.txt automatically. If you want to block search engine web crawlers completely from indexing your site, create layouts/robots.txt:

User-agent: *
Disallow: /

2. Custom RSS Feed with Smidr XSLT Styling

Smidr includes a custom XML stylesheet for RSS feeds (static/rss-style.xsl). Browsers that open /index.xml will render a dark-styled cyber feed rather than an unformatted XML tree, giving your readers a clean RSS subscription experience.
