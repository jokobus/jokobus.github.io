How to include Scalable Vector Graphics (svg) in $\LaTeX$

📅 17. Jul 2024 ⏱️ ~2 min read (279 words) #Howto #LaTeX

You may know the popular LaTeX package graphicx which you can use as:

\includegraphics[options]{filename}

graphicx does not support svg, but there is the package called svg that does the job.

How to use the svg package:

  1. Install Inkscape

    On Windows you can use winget.

    winget install -e --id Inkscape.Inkscape

  2. Copy your image.svg file into your document root folder (= right next to your .tex file)

  3. This is a minimal working example (MWE) for your .tex document:

    \documentclass{article}
\usepackage{svg}

\begin{document}
    \begin{figure}[htbp]
        \centering
        \includesvg[width=0.8\textwidth]{image}
        \caption{Vector graphic rendered directly from SVG.}
    \end{figure}
\end{document}

Notes & Tips:

  • The file extension is optional (image or image.svg both resolve properly).
  • You can pass standard sizing arguments in square brackets (width=10cm, height=5cm, scale=0.75).
  • Consult the official svg package documentation on CTAN for full parameters.

Troubleshooting Common Errors

Error 1: image_svg-tex.pdf' is missing

example.tex: error: 120: Package svg Error: File `image_svg-tex.pdf' is missing. \includesvg{image}
💡
Solution: Enable --shell-escape
The svg package invokes Inkscape in the background to convert SVG primitives into PDF format. To grant LaTeX permission to run external CLI binaries, you must pass the --shell-escape flag to your compiler.

In your TeX editor (e.g. TeXstudio under Settings $\rightarrow$ Commands $\rightarrow$ PdfLaTeX), update your build command:

pdflatex.exe -synctex=1 -interaction=nonstopmode --shell-escape %.tex

(If you are compiling with LuaLaTeX or XeLaTeX, append --shell-escape to their respective compiler command lines).

Error 2: Inkscape version not detected

example.tex: error: 119: Package svg Error: Inkscape version not detected. ...\includesvg{image}
⚠️
Solution: Add Inkscape to PATH
This indicates that the LaTeX compiler cannot locate the inkscape executable. Ensure Inkscape’s bin/ folder (on Windows typically C:\Program Files\Inkscape\bin) is added to your system PATH environment variable, or configure it under your editor’s custom commands.
