Installing PyTorch with CUDA & PyG in Conda

📅 30. Jun 2026 ⏱️ ~2 min read (355 words) #Conda #CUDA #PyTorch #Python #Deep Learning
📑 Table of Contents ▾
  • 1. Create an Isolated Conda Environment
  • 2. Install PyTorch with CUDA Wheel Binaries
  • 3. Verify PyTorch and CUDA Compatibility
  • 4. Install PyTorch Geometric (PyG) and Extension Wheels
  • 5. Comprehensive Hardware Verification Script

Setting up PyTorch with GPU acceleration and compiled C++/CUDA extension libraries (like PyTorch Geometric / PyG) often leads to subtle binary mismatch errors. Following this verified sequence ensures complete binary compatibility between PyTorch, the CUDA runtime, and PyG wheels.

1. Create an Isolated Conda Environment

Always start from a fresh environment with a supported Python version (Python 3.10 or 3.11 are currently the most broadly supported across deep learning wheels):

conda create -n torch_cu python=3.11 -y
conda activate torch_cu

2. Install PyTorch with CUDA Wheel Binaries

Upgrade pip within the environment, verify that which python points to the active Conda environment, and install PyTorch with the targeted CUDA index:

conda install pip -y
python -m pip install --upgrade pip

# Install PyTorch, torchvision, and torchaudio with CUDA 12.x / 13.x wheel support
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

Note: If your GPU requires CUDA 12.4 or 13.0+, adjust the index URL accordingly (e.g. cu124 or cu130).

3. Verify PyTorch and CUDA Compatibility

Before installing extension libraries, inspect the exact resolved PyTorch version and compiled CUDA tag:

python -c "import torch; print('Torch:', torch.__version__); print('CUDA Runtime:', torch.version.cuda); print('CUDA Available:', torch.cuda.is_available())"

Expected output:

Torch: 2.x.x+cu121
CUDA Runtime: 12.1
CUDA Available: True

4. Install PyTorch Geometric (PyG) and Extension Wheels

Install torch-geometric alongside its optional hardware-accelerated C++ kernels (pyg_lib, torch_scatter, torch_sparse, torch_spline_conv). Match the wheel directory URL to your exact PyTorch version and CUDA tag:

pip install torch-geometric

# Example for PyTorch 2.3.0 with CUDA 12.1 (replace with your matching versions)
pip install pyg_lib torch_scatter torch_sparse torch_spline_conv -f https://data.pyg.org/whl/torch-2.3.0+cu121.html

5. Comprehensive Hardware Verification Script

Run the following one-liner to verify that PyTorch detects your GPU, initializes CUDA context, and loads PyG without errors:

python -c '
import torch
import torch_geometric
import pyg_lib, torch_scatter, torch_sparse

print(f"PyTorch Version:    {torch.__version__}")
print(f"CUDA Available:     {torch.cuda.is_available()}")
if torch.cuda.is_available():
    print(f"Device Count:       {torch.cuda.device_count()}")
    print(f"Primary GPU:        {torch.cuda.get_device_name(0)}")
    print(f"VRAM Allocated:     {torch.cuda.memory_allocated(0) / 1024**2:.1f} MB")
print("PyG & C++ Kernels:  Loaded successfully!")
'

If successful, you will see your GPU model name (e.g. NVIDIA GeForce RTX ...) and a confirmation that all C++ kernels loaded cleanly. You can now proceed to install other packages via pip or conda.
