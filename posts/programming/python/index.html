Python Essentials: Complete Syntax & Concepts Guide

Python is a versatile, high-level language renowned for its readability, expressive syntax, and vast scientific ecosystem (NumPy, PyTorch, Pandas, Scipy). This guide compiles the fundamental language mechanics into an actionable reference.

1. Variables & Primitive Data Types

Python is dynamically typed and garbage collected:

# Integers, Floats, Strings, Booleans
count = 42
temperature = 98.6
language = "Python 3.12"
is_active = True

# Dynamic type inspection
print(type(count))        # <class 'int'>
print(type(temperature))  # <class 'float'>

Practical Examples

# List operations
fruits = ["apple", "banana", "cherry"]
fruits.append("orange")
print(fruits[1:3])  # Slicing: ['banana', 'cherry']

# Dictionary (Key-Value mappings)
user = {"id": 101, "role": "admin", "active": True}
user["email"] = "admin@example.org"

# Sets (Fast O(1) membership lookup & set theory)
tags_a = {"ai", "robotics", "python"}
tags_b = {"python", "web", "linux"}
common = tags_a & tags_b  # Intersection: {'python'}

3. List & Dictionary Comprehensions

Comprehensions provide concise syntax for creating sequences:

# Squares of even numbers
evens = [x**2 for x in range(10) if x % 2 == 0]
# [0, 4, 16, 36, 64]

# Inverting dictionary keys and values
lookup = {char: idx for idx, char in enumerate("ABC")}
# {'A': 0, 'B': 1, 'C': 2}

4. Functions, Lambdas & Arguments

# Default arguments and type hints
def greet(name: str, greeting: str = "Hello") -> str:
    return f"{greeting}, {name}!"

# Variable arguments (*args, **kwargs)
def summarize(*args, **kwargs):
    print("Positional:", args)
    print("Keyword:", kwargs)

# Anonymous Lambda function
square = lambda x: x ** 2

5. Object-Oriented Programming (Classes & Dataclasses)

from dataclasses import dataclass

@dataclass
class Point3D:
    x: float
    y: float
    z: float

    def distance_from_origin(self) -> float:
        return (self.x**2 + self.y**2 + self.z**2) ** 0.5

p = Point3D(1.0, 2.0, 2.0)
print(p.distance_from_origin())  # 3.0
