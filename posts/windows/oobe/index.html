What is OOBE?

OOBE is the Windows Out of Box Experience, that you have to click through after a fresh installation of Windows on your Computer. There you can set the system language, keyboard layout, connect to the internet and

Problem 1: Windows wants to force you to use a Microsoft Account

Microsoft wants you to use a Microsoft Account that is connected to their Cloud - to use all the amazing online Microsoft Features (and conveniently collect your data. Mpf). But instead of adding a Button “Use local account instead” they lay stones in your path. What a surprise! Solution 1 helps

Problem 2: You don’t have a internet connection at hand

If you don’t have an Internet connection at hand, Solution 1 works for you as well. Note: Now you have to create a Local Account, a Microsoft Account is not possible without an Internet connection. (But you can always switch/convert to a Microsoft Account in the account settings once you have finished setting Windows up - for whatever reason you should like to do that. )

Solution 1 & 2: Install Windows with a Local Account

Once booted a screen will show up to ask you to connect to your Wifi.

Instead, press Ctrl + F10 (or Fn + Ctrl + F10 if Fn always needs to be pressed for the function keys).

This will showm up a Command Prompt window. There type:

oobe \bypassnro

The computer will restart automatically. Afterwards, there will be a button Continue with limited setup in the step where you should setup the wifi. Click it and continue with setting up your Local Account.

Problem 3: Bypass OOBE temporarily

If you want to setup the computer with a Local Account, follow solution 1. This guide is for a different use case: You want to sell / give away your computer. You have Windows freshly installed and want to enter it (temporarily) to install drivers, updates or just see that everything is working fine. But you want that the person who gets the computer enters the OOBE and can setup everything else for themselve - with a fresh Feeling and no leftover config / wifi connection passwords from your side. In that case you can bypass OOBE.

Solution 3: Bypass OOBE temporarily

Method 1 - Key combination

Press the key combination Ctrl+Shift+F3. That should normally be the easiest way.

Note: Sometimes the Fn key is locked in the Bios Settings, then you would have to press Ctrl+Fn+Shift+F3.

Method 2

On the first OOBE screen, press Ctrl+F10 (or Ctrl+Fn+F10)

This will show up a Command Prompt window. There type:

cd \Windows\System32\oobe
msobe.exe /bypass

Restart the computer

shutdown /r /t

After the reboot, Windows should directly take you to the login screen.

Method 3 - Registry Entry

You can also try to set a OOBE entry in the Windows Registry.

  1. Press Shift+F10 to open the command prompt during the Windows setup.

Add a registry dword

reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /t REG_DWORD /d 0 /f

Restart your computer with

shutdown /r /t 0

On the next boot Windows should skip OOBE and log you in as a temporary administrator.

After you’re done, open Command Prompt (e.g. via the Startmenu) and execute

reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /t REG_DWORD /d 0 /f

or delete the key entirely

reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /f

Restart the computer and you should be directly taken back to the OOBE.
