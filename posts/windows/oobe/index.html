Howto bypass the Windows ‘Out of Box Experience’.

What is OOBE?

OOBE stands for the Windows Out-of-Box Experience—the initial wizard that greets you after a clean installation of Windows 11 or Windows 10. During this flow, you select your region, keyboard layout, connect to a network, and set up your user account.

Problem 1 & 2: Microsoft Account Requirement & Offline Setup

Starting with Windows 11 (especially editions 22H2 and newer), Microsoft enforces an active internet connection and requires signing in with a Microsoft Account (MSA) during setup. If you do not have an active Wi-Fi or Ethernet connection, or if you simply prefer a privacy-preserving Local Account, the installer prevents you from proceeding past the “Let’s connect you to a network” screen.

📝
Note
You can always link a Microsoft Account later in Windows Settings if you choose to use cloud-synced features like OneDrive or the Microsoft Store. Setting up with a local account first gives you full control over your user folder naming and telemetry preferences.

Solution 1: Bypass Network Requirement (BYPASSNRO)

The cleanest official mechanism built into Windows setup is the bypassnro (Bypass Network Requirement Option) command.

  1. On the “Let’s connect you to a network” screen, press:
    • Shift + F10 (or Fn + Shift + F10 on laptops where Function keys are inverted).
  2. A Command Prompt window will appear. Type the following command and press Enter:
    OOBE\BYPASSNRO
  3. Windows will automatically reboot.
  4. When you arrive back at the network screen, you will now see an additional option:
    • Click “I don’t have internet”.
    • On the next screen, click “Continue with limited setup”.
  5. Enter your preferred username and password to create a traditional local user account.
💡
Tip
Legacy Email Trick: Alternatively, if you already have network connectivity, you can enter a blocked dummy email like no@thankyou.com with any random password. Windows will display an error message (“Oops, something went wrong”) and immediately offer to create a local account instead.

Problem 3: Preparing a PC for Sale or Handover (Audit Mode)

If you are assembling, configuring, or selling a computer, you may want to:

  • Install manufacturer device drivers, updates, and benchmark software.
  • Verify hardware stability and audio/GPU functionality.
  • Ensure that the final buyer still experiences the clean, original OOBE greeting without seeing your test user profile or Wi-Fi network saved.

Solution 2: Enter Windows Audit Mode

Method 1 — The Sysprep Audit Mode Shortcut (Recommended)

Microsoft provides a built-in staging mode specifically for OEMs and system builders called Audit Mode.

  1. At the very first OOBE setup screen (where it asks for your country or region), press:
    • Ctrl + Shift + F3 (or Ctrl + Shift + Fn + F3).
  2. The computer will immediately reboot and automatically sign into the built-in Administrator account in Audit Mode.
  3. A System Preparation Tool (Sysprep) dialog will remain open on the desktop.
  4. Now you can install hardware drivers, run benchmarks, and install essential utilities.
⚠️
Warning
Do not close the Sysprep dialog window. If you accidentally close it, you can relaunch it anytime by running: C:\Windows\System32\Sysprep\sysprep.exe
  1. Once you are finished preparing the machine:
    • In the Sysprep window, set System Cleanup Action to Enter System Out-of-Box Experience (OOBE).
    • Check the Generalize box (optional, recommended if you are imaging).
    • Set Shutdown Options to Shutdown.
    • Click OK.
  2. When the buyer powers on the device, it will boot directly into the fresh OOBE wizard.

Method 2 — Temporary Registry Override

If you want to manually toggle setup completion state from the command line:

▸ Show Registry Bypass Instructions
  1. Press Shift + F10 during setup to open Command Prompt.
  2. Mark setup as temporarily completed:
    reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /t REG_DWORD /d 1 /f
shutdown /r /t 0
  3. After rebooting, Windows will proceed directly to login.
  4. When finished testing, revert the flag so the next user is sent back to OOBE:
    reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Setup" /v "OOBEComplete" /f
shutdown /r /t 0
