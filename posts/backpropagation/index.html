Backpropagation in Standard Calculus

Introduction

This article explains the backpropagation algorithm for training Artificial Neural Networks using standard scalar calculus notation, as popularized by Rumelhart, Hinton, and Williams [rumelhart1986] and framed theoretically by LeCun [lecun1988] . If you prefer a vectorized multi-variable derivation, see the companion guide: Backpropagation in Matrix Calculus.

Learning Process

Consider a 2-layer Neural Network (one hidden layer and one output layer) as shown below. We want to train the network so that the training inputs $x$ correctly produce the expected target labels $t$.

For training, we use a dataset containing paired samples $(x, t)$. Each pair is used to adjust the network parameters to minimize the difference between the network’s prediction $y$ and the actual target $t$. Thinking of the network as a function $y = f(x)$, our goal is to adjust $f(x)$ until the prediction error is as small as possible. A smaller error means the predictions closely match ground truth labels.

Training this neural network comes down to finding weight values that yield predictions $y = f(x)$ as close as possible to the target $t$, especially on unseen test data.

Training Algorithm

The high-level training process follows this structure:

Loop over epochs
    Loop over all training samples (x, t)
        1. Feedforward pass (compute predictions y)
        2. Compute total error E between prediction y and target t
        3. Backpropagate error and calculate gradients
        4. Update weights using gradient descent
    End loop
End loop
  1. Feedforward phase: Covered in detail in the Article about the Feedforward Phase.
  2. Error calculation: Measured using the squared error sum:
$$E = \frac{1}{2}\sum_i (t_i - y_i)^2$$

For an output node $i$, the error contribution is $E_i = \frac{1}{2}(t_i - y_i)^2$. The factor $\frac{1}{2}$ is added so that taking derivative cancels the constant factor:

$$\frac{\partial E_i}{\partial y_i} = \frac{1}{2} \cdot 2 \cdot (t_i - y_i) \cdot (-1) = -(t_i - y_i) = y_i - t_i$$
  1. Backpropagation phase: Applies the chain rule backwards through the network layers to calculate how much each weight contributed to the final error.

The Chain Rule

The goal of backpropagation is to calculate the derivative of the loss function $E$ with respect to every weight $w$ in the network: $\frac{\partial E}{\partial w}$. Once we know this rate of change, we can adjust the weight in the direction that decreases the error.

Since a weight deep in the network influences the output through a series of nested calculations, we use the calculus chain rule. For a composed function $y = f(g(x))$, the derivative with respect to $x$ is:

$$\frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}$$

In neural networks, we apply this rule step-by-step from the output layer backwards to the input layer.

1. Output Layer Weights

Let $w_{ij}^{(2)}$ be the weight connecting hidden unit $h_j$ to output unit $y_i$.

The output calculation at node $i$ consists of two steps:

  1. Weighted sum plus bias:
$$z_i^{(2)} = \sum_{j} w_{ij}^{(2)} h_j + b_i^{(2)}$$
  1. Activation function application (e.g., Sigmoid $\sigma$):
$$y_i = \sigma(z_i^{(2)})$$

To find how changes in $w_{ij}^{(2)}$ affect total loss $E$, we decompose $\frac{\partial E}{\partial w_{ij}^{(2)}}$ into three partial derivatives:

$$\frac{\partial E}{\partial w_{ij}^{(2)}} = \frac{\partial E}{\partial y_i} \cdot \frac{\partial y_i}{\partial z_i^{(2)}} \cdot \frac{\partial z_i^{(2)}}{\partial w_{ij}^{(2)}}$$

Let’s compute each term:

  • Term 1: Derivative of error w.r.t. output prediction
$$\frac{\partial E}{\partial y_i} = (y_i - t_i)$$
  • Term 2: Derivative of activation function w.r.t. weighted sum
$$\frac{\partial y_i}{\partial z_i^{(2)}} = \sigma'(z_i^{(2)})$$

(For the sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$, the derivative is $\sigma(z)(1 - \sigma(z))$).

  • Term 3: Derivative of weighted sum w.r.t. weight
$$\frac{\partial z_i^{(2)}}{\partial w_{ij}^{(2)}} = h_j$$

Combining these terms:

$$\frac{\partial E}{\partial w_{ij}^{(2)}} = (y_i - t_i) \cdot \sigma'(z_i^{(2)}) \cdot h_j$$

To simplify notation, define the error term (or local gradient) $\delta_i^{(2)}$ for output node $i$:

$$\delta_i^{(2)} = \frac{\partial E}{\partial z_i^{(2)}} = (y_i - t_i) \sigma'(z_i^{(2)})$$

This lets us express the gradient cleanly as:

$$\frac{\partial E}{\partial w_{ij}^{(2)}} = \delta_i^{(2)} h_j$$

2. Hidden Layer Weights

Now consider weight $w_{jk}^{(1)}$ in the first layer, connecting input $x_k$ to hidden node $h_j$.

The weighted sum and activation for hidden node $h_j$ are:

$$z_j^{(1)} = \sum_{k} w_{jk}^{(1)} x_k + b_j^{(1)}$$$$h_j = \sigma(z_j^{(1)})$$

Hidden node $h_j$ feeds into all output nodes in the next layer. Therefore, changing $w_{jk}^{(1)}$ alters $h_j$, which propagates through every output node $i$. By the multivariate chain rule, we sum the contributions over all output nodes $i$:

$$\frac{\partial E}{\partial w_{jk}^{(1)}} = \left( \sum_{i} \frac{\partial E}{\partial z_i^{(2)}} \cdot \frac{\partial z_i^{(2)}}{\partial h_j} \right) \cdot \frac{\partial h_j}{\partial z_j^{(1)}} \cdot \frac{\partial z_j^{(1)}}{\partial w_{jk}^{(1)}}$$

Breaking down these components:

  • From the output layer analysis, $\frac{\partial E}{\partial z_i^{(2)}} = \delta_i^{(2)}$.
  • The derivative of output linear combination w.r.t hidden activation is:
$$\frac{\partial z_i^{(2)}}{\partial h_j} = w_{ij}^{(2)}$$
  • The activation derivative is:
$$\frac{\partial h_j}{\partial z_j^{(1)}} = \sigma'(z_j^{(1)})$$
  • The derivative w.r.t the weight itself is:
$$\frac{\partial z_j^{(1)}}{\partial w_{jk}^{(1)}} = x_k$$

Substituting these back into our expression gives:

$$\frac{\partial E}{\partial w_{jk}^{(1)}} = \left( \sum_{i} \delta_i^{(2)} w_{ij}^{(2)} \right) \cdot \sigma'(z_j^{(1)}) \cdot x_k$$

Defining the hidden layer error term $\delta_j^{(1)}$:

$$\delta_j^{(1)} = \left( \sum_{i} \delta_i^{(2)} w_{ij}^{(2)} \right) \sigma'(z_j^{(1)})$$

The gradient simplifies to:

$$\frac{\partial E}{\partial w_{jk}^{(1)}} = \delta_j^{(1)} x_k$$

Notice the pattern: for any weight connecting node $A$ to node $B$, the gradient is equal to the error term $\delta$ at node $B$ multiplied by the activation input from node $A$.

Updating Weights with Gradient Descent

Once gradients are computed for all weights and biases, parameters are updated in the direction opposite to the gradient to minimize total loss $E$:

$$w_{ij}^{(2)} \leftarrow w_{ij}^{(2)} - \eta \frac{\partial E}{\partial w_{ij}^{(2)}}$$$$w_{jk}^{(1)} \leftarrow w_{jk}^{(1)} - \eta \frac{\partial E}{\partial w_{jk}^{(1)}}$$

Where $\eta > 0$ is the learning rate, controlling the step size of each update. Biases are updated identically using their respective $\delta$ terms:

$$b_i^{(2)} \leftarrow b_i^{(2)} - \eta \, \delta_i^{(2)}$$$$b_j^{(1)} \leftarrow b_j^{(1)} - \eta \, \delta_j^{(1)}$$

Summary

Backpropagation breaks down loss optimization into two steps:

  1. Forward Pass: Compute activation outputs layer-by-layer up to prediction $y$.
  2. Backward Pass: Calculate output error terms $\delta^{(2)}$, propagate them backward to compute hidden layer error terms $\delta^{(1)}$, and scale by layer inputs to get weight gradients.

While scalar notation makes intermediate dependencies easy to track, vectorized implementations run much faster on hardware. Check out Backpropagation in Matrix Calculus to see how these operations translate directly into matrix multiplications.
