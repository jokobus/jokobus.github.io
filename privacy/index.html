Privacy at a Glance

This website follows a strict privacy-by-design approach:

  • Zero Tracking Cookies: No marketing, profiling, or cross-site tracking cookies are set in your browser.
  • No Third-Party Advertising: No advertising networks, social media widgets, or behavioral analytics scripts are embedded.
  • Local WebAssembly Execution: Interactive code runners and widgets (such as Python code via Pyodide) execute 100% locally in your browser without transmitting your code or input to an external cloud server.

1. Responsible Party & Scope

This privacy statement informs users about the type, scope, and purpose of personal data collection on this website pursuant to the EU General Data Protection Regulation (GDPR / DSGVO).

For privacy-related inquiries, please contact the site operator via the Contact Form.

2. Server Log Files

When accessing this website, the hosting infrastructure (such as GitHub Pages or a private self-hosted web server) automatically logs technical connection data transmitted by your browser. This includes:

  • IP address of the requesting device
  • Date and time of the request
  • Requested URL / resource path
  • HTTP response status code
  • Referrer URL (previously visited page, if sent by your browser)
  • Browser type, version, and operating system

Purpose and Legal Basis:
This data is processed pursuant to Art. 6(1)(f) GDPR on the basis of legitimate interest in ensuring system stability, detecting technical faults, and defending against cyberattacks or DDoS attacks. This log data is stored temporarily by the server and is not merged with any other personal data sources.

3. Contact Form

When you submit a message using the contact form, the details you enter (name, email address, message body) are encrypted in transit via SSL/TLS and transmitted to process your inquiry.

Purpose and Legal Basis:
Processing of this data is based on Art. 6(1)(b) GDPR (handling inquiries or pre-contractual requests) and Art. 6(1)(f) GDPR (legitimate interest in responding efficiently to incoming communication). Your contact details are never shared with unauthorized third parties or used for unsolicited promotional purposes.

4. Cryptographic Communication

If you communicate with the site operator, end-to-end encrypted communication (e.g., via OpenPGP) can be utilized upon request. No personal identity data is collected during this process beyond the standard server logs mentioned above.

5. Your Rights as a Data Subject

Under the GDPR, you have the following rights regarding any personal data concerning you:

  • Right of Access (Art. 15 GDPR): Request confirmation as to whether personal data is being processed and obtain a copy.
  • Right to Rectification (Art. 16 GDPR): Request correction of inaccurate data.
  • Right to Erasure (Art. 17 GDPR): Request deletion of your personal data (“right to be forgotten”).
  • Right to Restriction of Processing (Art. 18 GDPR): Request limitation of data processing under statutory conditions.
  • Right to Object (Art. 21 GDPR): Object at any time to processing based on legitimate interests.

To exercise any of these rights, please send a message via the Contact Form.
